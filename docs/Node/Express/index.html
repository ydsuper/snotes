Express

Express 介绍​

基于 Node.js 平台，快速、开放、极简的 Web 开发框架
Express 是一个简洁而灵活的 node.js Web 应用框架，提供了一系列强大特性帮助你创建各种 Web 应用，和丰富的 HTTP 工具。利用它能快速搭建一个完整功能的网站

Express框架核心特性
 • 可以设置中间件响应HTTP请求
 • 定义了路由表用于执行不同的HTTP请求动作
 • 可以通过向模板传递参数来动态渲染HTML页面

Express 基本使用​

// 1.引入模块
const express = require("express");

// 2.框架模块创建服务
const app = express();

// 3.监听请求 返回数据(中间件)
app.use((req, res) => {
  // res.write('你好');
  // res.end();

  // send自动识别字符串 不会乱码
  res.send("你好");
});

// 4.指定端口 启动服务
app.listen(80, () => {
  console.log("http://localhost:80");
});

GET 和 POST 的不同请求​

GETPOST
后退/刷新无害数据会被重新提交(浏览器应该告知用户数据会被重新提交)
书签可收藏为书签不可收藏为书签
缓存能被缓存不能缓存
编码类型application/x-www-form-urlencodedapplication/x-www-form-urlencoded 或 multipart/form-data。为二进制数据使用多重编码
历史参数保留在浏览器历史中参数不会保存在浏览器历史中
对数据长度的限制是的。当发送数据时， GET 方法向 URL 添加数据;URL 的长度是受限制的(URL 的最大长度是 2048 个字符)无限制
对数据类型的限制只允许 ASCII 字符没有限制，也允许二进制数据
安全性与 POST 相比，GET 的安全性较差，因为所发送的数据是 URL 的一部分。在发送密码或其他敏感信息时绝不要使用 GETPOST 比 GET 更安全，因为参数不会被保存在浏览器历史或 web 服务器日志中
可见性数据在 URL 中对所有人都是可见的数据不会显示在 URL 中

GET 请求​

凡是地址栏的输入，a或者link标签的href，script或者img中的src等请求都是GET请求 

const express = require("express");
const app = express();
// GET实现路由
app.get("/", (req, res) => {
  res.send("当前是首页");
});
app.get("/index", (req, res) => {
  res.send("当前是首页");
});
app.get("/login", (req, res) => {
  res.send("当前是登录页");
});
app.get("/list", (req, res) => {
  res.send("当前是列表页");
});

中间件​

中间件就是一堆方法，可以接受客户端发来的请求，可以对请求做出响应，也可以将请求继续交给下一个中间件继续处理。

发送请求-- > 中间件处理请求-- > 中间件处理请求-- > 响应;
中间件主要有两部分构成：'中间件方法' 和 '请求处理函数'
'中间件方法': 由Express提供，负责拦截请求
'请求处理函数': 有开发人员提供，负责处理请求

next()方法​

针对同一个请求设置多个中间件，默认情况下，请求从上到下依次匹配中间件，匹配成功后终止匹配。可调用next()方法将请求的控制权交给下一个中间件，直到结束请求。

app.get("/request", (req, res, next) => {
  req.name = "张三";
  next();
});
app.get("/request", (req, res) => {
  res.send(req.name); // 张三
});

app.use 中间件​

app.use可匹配所有的请求方式

// app.use直接传入请求处理函数，代表接收所有的请求
app.use((req, res, next) => {
  console.log("任何请求都会打印这句话");
  next();
});
// app.use第一个参数传入请求地址，代表任何请求方式，是该请求地址就接受该请求
app.use("/admin", (req, res, next) => {
  console.log("是该请求地址就会打印这句话");
  next();
});

中间件应用​

// 网站维护
app.use((req, res, next) => {
  res.send("网站正在维护中...");
});
// 路由保护，登录才能访问
app.use("/admin", (req, res, next) => {
  // 用户登录标识
  let isLogin = true;
  // let isLogin = false;

  if (isLogin) {
    next();
  } else {
    res.send("您还没有登录，不能访问 /admin 页面");
  }
});
app.get("/admin", (req, res) => {
  res.send("宁已经登录，可以访问！");
});
// 自定义404页面
app.use((req, res, next) => {
  res.status(404).send(404);
});

错误处理中间件​

在程序执行的过程中，不可避免的会出现一些无法预料的错误，比如文件读取失败，数据库连接失败。错误处理中间件是一个集中处理错误的地方。（开发时异常 运行时异常）

app.get("/index", (req, res, next) => {
  // 抛异常（开发时异常 尽量自己解决 执行时异常 抛）
  throw new Error("程序发生未知错误");
});
// app.use会拦截所有的请求
app.use((err, req, res, next) => {
  console.log(err.message);
  res.status(500).send(err.message);
});
// 当程序错误时，调用next()方法，将错误信息通过参数的形式传递给next()方法，即可触发错误处理中间件
app.get("/index", (req, res, next) => {
  // 读取文件 [错误]
  fs.readFile("./abc.txt", "utf8", (err, data) => {
    if (err != null) {
      next(err);
    } else {
      res.send(data);
    }
  });
});
// app.use会拦截所有的请求
app.use((err, req, res, next) => {
  console.log(err.message);
  res.status(500).send(err.message);
});

构建模块化路由​

const express = require("express");

// home.js
const home = express.Router();
// localhost/home/index
home.get("/index", () => {
  res.send("欢迎来到博客展示页面");
});
module.exports = home;

// admin.js
const admin = express.Router();
// localhost/admin/index
admin.get("/index", () => {
  res.send("欢迎来到博客管理页面");
});
module.exports = admin;

// app.js
const app = express();
const home = require("./route/home.js");
const admin = require("./route/admin.js");
// 二级路由
app.use("/home", home);
app.use("/admin", admin);

模板引擎之 artTemplate​

为了使art-template模板引擎能够更好的和Express框架配合，模板引擎官方在原art-template模板引擎的基础上封装了express-art-template。 使用npm install art-template express-art-template命令进行安装。

// 当渲染后缀为art的模板时 使用express-art-template
app.engine("art/html", require("express-art-template"));
// 设置模板存放目录
app.set("views", path.join(__dirname, "views"));
// 渲染模板时不写后缀 默认拼接art后缀
app.set("view engine", "art/html");
app.get("/", (req, res) => {
  // 渲染模板
  res.render("index");
});

artTemplate 解析规则​

art-template 可以自定义模板解析规则，默认配置了原始语法与标准语法。

//【template.defaults.rules】
// 原始语法的界定符规则
template.defaults.rules[0].test = /<%(#?)((?:==|=#|[=-])?)[ \t]*([\w\W]*?)[ \t]*(-?)%>/;
// 标准语法的界定符规则
template.defaults.rules[1].test = /{{([@#]?)[ \t]*(\/?)([\w\W]*?)[ \t]*}}/;
