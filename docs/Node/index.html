Node.js 中模块的加载机制​

模块查找规则-当模块拥有路径但没有后缀时​
require('./find.js')
require('./find')

[规则]:
1. require方法根据模块路径查找模块，如果是完整路径，直接引入模块。
2. 如果模块后缀省略，先找同名JS文件再找同名JS文件夹
3. 如果找到同名文件夹 会去查看该文件夹中的package.json中的main选项中的模块入口文件（默认是index.js）
4. 如果找不到指定的入口文件就会报错，模块没有被找到
模块查找规则-当模块没有路径且没有后缀时​
require('find')

[规则]:
1. Node.js会假设它是系统模块
2. Node.js会去node_modules文件夹中
3. 首先看是否有同名的JS文件 再看是否有同名的文件夹
4. 如果找到同名文件夹 会去查看该文件夹中的package.json中的main选项中的模块入口文件（默认是index.js）
5. 如果找不到指定的入口文件就会报错，模块没有被找到

服务器概念​

网站组成​

网站应用程序主要分为两大部分：客户端和服务器端。

'客户端': 在浏览器中运行的部分，就是用户看到并与之交互的界面程序。使用HTML、CSS、JavaScript构建
'服务器端': 在服务器中运行的部分，负责存储数据和处理应用逻辑
web 服务器​

服务器(提供服务)指的就是一台安装特点软件的计算机，用于专门提供特定的服务。 客户端(使用服务)指的是在一次服务过程中使用这个服务的设备(网络端点)。

| 按照服务类型的不同，又划分为：Web服务器、数据库服务器、文件服务器等
| 目前最常见的客户端就是浏览器
B/S 架构与 C/S 架构​
B/S架构: Browser（浏览器）Server（服务器），都通过浏览器访问使用，服务器提供数据存储等服务
C/S架构: Client（客户端）Server（服务器），通过安装软件使用，服务器提供数据存储等服务
Node 网站服务器​

能够提供网站访问服务的机器就是网站服务器，它能够接收客户端的请求，能够对请求做出响应。

开发过程中客户端和服务器端说明​

在开发阶段，客户端和服务器端使用同一台电脑，即开发人员电脑。

开发人员电脑: 客户端（浏览器）、服务器端（Node）
本机域名：localhost
本地IP：127.0.0.1
请求响应流程​
1.打开浏览器
2.输入访问的网站地址(URL)
3.浏览器通过DNS服务器 获取即将访问的网站的IP地址
4.浏览器发起一个对这个IP地址的请求
5.服务端监听指定的 端口 的服务器软件接收到这个请求，进行相应的处理
6.服务端将处理完的结果返回给客户端浏览器(响应)
7.浏览器将服务端返回的结果呈现到界面上

创建 web 服务器​

// 1. 引用系统模块
const http = require("http");

// 2. 创建web服务器 createServer()
const app = http.createServer();

// 3. 当客户端发送请求时 处理响应
app.on("request", (req, res) => {
  // req：request 浏览器发起的请求 请求服务器做某事
  // res：response 服务器发起响应 发送一些结果给浏览器
  // 响应如下：
  // res.write('<h1>Hello, boy!</h1>');
  // res.end();
  // 只发送一次 可直接res.end()
  res.end("<h1>Hello, boy!</h1>");
});

// 4. 监听端口 启动服务
app.listen(3000, () => {
  console.log("请打开：http://127.0.0.1:3000 或 localhost:3000");
});

HTTP 协议​

超文本传输协议（英文：HyperText Transfer Protocol，缩写：HTTP）规定了如何从网站服务器传输超文本到本地浏览器，它基于客户端服务器架构工作，是客户端（用户）和服务器端（网站）请求和应答的标准。

报文​

在HTTP请求和响应的过程中传递的数据块就叫报文，包括要传送的数据和一些附加信息，并且要遵守规定好的格式。

'http请求报文'
 请求方式  请求地址  请求协议/版本  --> 请求行
 各种各样的请求头：[键: 值]  --> 请求头
 请求内容  --> 请求主体

'http响应报文'
 协议/版本号 状态码  --> 响应行
 各种各样的响应头：[键: 值]  --> 响应头
 响应内容  --> 响应主体
请求报文​
// 1、请求的方式
GET-- > 请求数据;
POST-- > 发送数据;
PUT-- > 修改数据;
DELETE-- > 删除数据;
// 2、请求的格式
app.on("request", (req, res) => {
  req.method; // 获取请求方式
  req.url; // 获取请求地址
  req.headers; // 获取请求报文
});
响应报文​
// 设置响应报文
res.writeHead(响应状态码, 响应头)

// 1.HTTP状态码

 1xx 信息  2xx 成功  3xx 重定向  4xx 客户端错误  5xx 服务器错误
// 2.内容类型 大类型/具体类型
 text/html

 application/json

const app = http.createServer();
app.on("request", (req, res) => {
  // 将url路径的各个部分解析出来并返回对象
  // true 代表将参数解析为对象格式
  let { query } = url.parse(req.url, true); // 直接获取Url的query
  console.log(query); // {键: 值}
});

POST 请求参数​

参数被放置在请求体中进行传输 获取POST参数需要使用data事件和end事件 使用querystring系统模块将参数转换为对象格式

// 导入系统模块querystring 用于将HTTP参数转换为对象格式
const querystring = require("querystring");
app.on("request", (req, res) => {
  let postData = "";
  // 监听参数传输事件
  req.on("data", (chunk) => {
    // chunk数据：字符串的16进制表示
    // 传输中 无法保证数据传输完整，采用拼接方式 获取完整数据
    postData += chunk;
  });
  // 监听参数传输完毕事件
  req.on("end", () => {
    // querystring.parse 转对象
    console.log(querystring.parse(postData));
  });
});
路由​

路由是指客户端请求地址与服务器端程序代码的对应关系。简单来说，请求什么响应什么。

http://localhost:80/index ->响应主页
http://localhost:80/login?username=admin&password=123456 ->响应登录页

// 当客户端发来请求时
app.on('request', (req, res) => {
    // 支持中文
    res.writeHead(200, {
        'Content-Type': 'text/html;charset=utf8'
    })
    // 获取客户端的请求路径
    let { pathname } = url.parse(req.url);
    if (pathname == '/' || pathname == '/index') {
        res.write('<h1>欢迎来到首页</h1>')
        res.end(`<a href="./login?username=gg&password=123">登录页面</a>`)
    } else if (pathname == '/login') {
        res.write('<h1>欢迎来到登录页面</h1>')
        res.end(`<a href="./index?id=110">首页</a>`)
    } else {
        res.end('<h1>对不起，您访问的页面不存在</h1>')
    }
});

Promise​

Promise出现的目的是解决Node.js异步编程中回调地狱的问题。

// Promise是ES(js)中的一个内置对象
// resolve成功时回调 | reject失败时回调
const promise = new Promise((resolve, reject) => {
  resolve("Promise成功");
})
  .then((result) => {
    console.log(result); // Promise成功
  })
  .catch((err) => {
    console.log(err); // 错误
  });
异步函数​

异步函数是异步编程语法的终极解决方案，它可以让我们将异步代码写成同步的形式，让代码不再有回调函数嵌套，使代码变得清晰明了。

const fn = async () => {};
async function fn() {}
async 关键字​
1. 普通函数定义前加async关键字 普通函数变成异步函数
2. 异步函数默认返回promise对象
3. 在异步函数内部使用return关键字进行结果返回 结果会被包裹的promise对象中 return关键字代替了resolve方法
4. 在异步函数内部使用throw关键字抛出程序异常
5. 调用异步函数再链式调用then方法获取异步函数执行结果
6. 调用异步函数再链式调用catch方法获取异步函数执行的错误信息
await 关键字​
1. await关键字只能出现在异步函数中
2. await promise await后面只能写promise对象 写其他类型的API是不可以的
3. await关键字可是暂停异步函数向下执行 直到promise返回结果

静态目录​

搭建服务器在本地网址输入对应页面，实施对应目录文件的跳转。略简化路由

// 1.引入模块
// 1.1 引入http模块
const http = require("http");
// 1.2 引入url模块
const url = require("url");
// 1.3 引入fs模块
const fs = require("fs");
// 1.4 引入path模块
const path = require("path");
// 1.5 引入mime模块（第三方）
const mime = require("mime");

// 2.创建服务
const app = http.createServer();

// 3.监听客户端的request事件 处理请求
app.on("request", (req, res) => {
  res.writeHead(200, {
    "Content-Type": "text/html;charset=utf8",
  });

  // 获取文件路径
  // let {pathname} = url.parse(req.url);
  let pathname = url.parse(req.url, true).pathname;
  // console.log(pathname); // /public/index.html 【获取的是localhost后面的pathname】

  // 获取文件绝对路径
  let absolutePath = path.join(__dirname, pathname);
  // console.log(absolutePath); // 当前文件夹的绝对路径+\public\index.html

  // readFile读取文件
  fs.readFile(absolutePath, (err, data) => {
    // 如果错误 Not Found
    if (err != null) {
      res.writeHead(404, {
        // text/plain设置文件为纯文本的形式，浏览器在获取到这种文件时并不会对其进行处理
        "Content-Type": "text/plain;charset=utf8",
      });
      res.end("Not Found");
      return false;
    }

    // 操作计算机识别不同文件类型
    let type = mime.getType(absolutePath);
    res.writeHead(200, {
      "Content-Type": type,
    });
    res.end(data);
  });

  // res.end('<h1>--END--</h1>');
});

// 4.指定端口 启动服务
app.listen(80, () => {
  console.log("http://localhost:80");
});

    let options = {
      host: 主机名,

    exports.query = function (sql, values) {
      return new Promise((resolve, reject) => {
        pool.getConnection(function (err, connection) {
          if (err) {
            reject(err);
            //console.log(err, "数据库连接失败");
            resolve({
              status: 500,
            });
          } else {
            //console.log("数据库连接成功");
            connection.query(sql, values, (err, results) => {
              if (err) {
                reject(err);
                resolve({
                  status: 400,
                });
              } else {
                connection.release();
                resolve({
                  status: 200,
                  results,
                });
              }
            });
          }
        });
      });
    };
