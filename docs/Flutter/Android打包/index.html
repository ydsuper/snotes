Android 打包

参考：基本操作文档

配置 app 图标 非必须​

1. 进入项目文件夹中的 /android/app/src/main/res

2. 能看到多个以mipmap-为前缀的文件夹 文件夹名的后缀就对应的是app图标像素密度

'后缀'     '像素密度'       '像素'
 mdpi      ~160dpi        48 * 48 px
 hdpi      ~240dpi        72 * 72 px
 xhdpi     ~320dpi        96 * 96 px
 xxhdpi    ~480dpi        144 * 144 px
 xxxhdpi   ~640dpi        192 * 192 px

3. 将对应像素图片放入对应的文件夹中, 图片记得用png格式，安装的app会根据对应的屏幕像素密度使用适应尺寸的图标, 但要注意, app图标文件最好统一使用同一个名字, 方便配置!

配置 app 名称、图标和系统权限 非必须​

1. 进入项目文件夹中的 /android/app/src/main/AndroidManifest.xml

2. 在application标签中:
   //此属性为app安装到手机上显示的名称，支持中文
   android:label="flutter_app"
   //此属性为app图标用到的图片名称：@mipmap/统一的图标名称
   android:icon="@mipmap/ic_launcher"

"注：图片文件不需要输入格式后缀，使用相同文件名，方便此处配置，因为此处没有按像素分别配置对应图片"

3. 使用uses-permission标签：此标签定义APP的系统权限，比如打开麦克风摄像头、获取联系人号码簿、是否允许上网等，权限有很多，具体请参考官网

[相关权限文档]: https://www.cnblogs.com/damowang/p/4336090.html
// 允许程序录制音频
<uses-permission android:name="android.permission.RECORD_AUDIO" />
// 允许读用户外部存储
<uses-permission android:name="android.permission.READ_EXTERNAL_STORAGE" />
// 允许应用写（非读）用户的外部存储器
<uses-permission android:name="android.permission.WRITE_EXTERNAL_STORAGE" />
// 允许手机联网
<uses-permission android:name="android.permission.INTERNET" />

app 注册 重点​

1. 生成 keystore​

# 1.1 在终端下输入下方命令
keytool -genkey -v -keystore x:/[key所创路径]/key.jks -keyalg RSA -keysize 2048 -validity 100000 -alias key

# 如果报错找不到keytool，需要先把 java 命令所在目录添加到 PATH 环境变量中

例：keytool -genkey -v -keystore D:/demo/key.jks -keyalg RSA -keysize 2048 -validity 100000 -alias key

// 1.2 按照问题填写信息，填完即可发现对应目录下多出了一个key.jks文件
       "注：不要把这个jks文件共享给任何人！！！"

// 1.3 到项目目录的android文件夹下创建一个名为key.properties的文件
[复制以下代码]
//输入创建key.jks时输入的 密钥库 密码
storePassword=xxxxxx
//确认输入创建key.jks时输入的 密钥 密码
keyPassword=xxxxxx
keyAlias=key
//key.jks的存放路径 [注意斜杠符号]
storeFile=x:/key所在路径/key.jks

"注：这个key.properties文件也不要共享出去！！！"

2. 配置 key 注册​

2.1 进入项目文件夹中的 /android/app/build.gradle

2.2 在 android { 这一行前面，加入代码:
def keystorePropertiesFile = rootProject.file("key.properties")
def keystoreProperties = new Properties()
keystoreProperties.load(new FileInputStream(keystorePropertiesFile))

2.3 将如下代码替换：
//【待替换】
buildTypes {
   release {
       signingConfig signingConfigs.debug
   }
}

//【替换后】
signingConfigs {
   release {
       keyAlias keystoreProperties['keyAlias']
       keyPassword keystoreProperties['keyPassword']
       storeFile file(keystoreProperties['storeFile'])
       storePassword keystoreProperties['storePassword']
   }
}

buildTypes {
   release {
       signingConfig signingConfigs.release
       shrinkResources false //[关闭删除无用代码]
       minifyEnabled false //[关闭删除无用资源]
   }
}

2.4 到defaultConfig中，录入APPID和版本号
defaultConfig {
   // APPID
   applicationId "com.example.myflutter"
   // 可运行应用的最低版本的 Android 平台，由该平台的 API 级别标识符指定
   minSdkVersion 16
   // 指定运行应用的目标 API 级别。
   // 在某些情况下，这允许应用使用在目标 API 级别中定义的清单元素或行为，
   // 而不是仅限于使用那些针对最低 API 级别定义的元素或行为。
   targetSdkVersion 27
   //内部版本号
   versionCode 1
   //对外公布的版本号
   versionName "1.0"
   testInstrumentationRunner "android.support.test.runner.AndroidJUnitRunner"

   ndk {
    abiFilters "armeabi-v7a","arm64-v8a" //限定打包支持的CPU处理器架构 [可以降低apk安装包大小]
   }
}

// 3.1 项目根目录 终端输入命令：
flutter build apk
