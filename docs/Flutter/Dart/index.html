Dart 语言

Dart 概述​

Dart是Goole发布的一门开源编程语言
Dart初期目标是成为下一代的web开发语言 [如今已是javascript]
Dart目前已可用于全平台开发
Dart是一门面向对象的编程语言
// 应用场景
1.Web开发
2.跨平台移动应用开发（Flutter）
3.脚本或服务端开发

数据类型​

变量和常量​

变量​

使用var声明变量，可赋予不同类型的的值，未初始化时，默认值为null。 使用final可声明一个只能赋值一次的变量。

void main() {
// var变量
  var num;
  print(num); //null
  num = 10;
  print(num); //10

// final只赋值一次的变量
  final num2 = 20;
  // num2 = 21; //报错
  print(num2); //20
}
常量​

使用const声明常量，声明的必须是编译器常量。

void main() {
// const常量
  const num3 = 30;
  print(num3); //30
}

数值型​

数值型有int（整型），double（浮点型），dart的数值型的方式和属性与javascript差不多，不过，dart的数值型多了一个‘~/’，相除求整的运算符。

void main() {
  // int整型和double浮点型
  int a = 10;
  // a = 10.1; //报错
  print(a); //10

  double b = 10.5;
  b = 10;
  print(b); //10.0
}
运算符​

+-*/，%，~/(取整)

void main() {

  print(1 + 1);
  print(1 - 1);
  print(1 * 1);
  print(2 / 1); //2.0 除出来是浮点型
  print(1 % 2);
  print(2 ~/ 1);

列表方法​

  var list = [1, 2, 3];
  print(list.length); //3

  list.add(4);
  list.add(4);
  print(list); //[1, 2, 3, 4]

  list.forEach(print); //遍历打印 [传入方法]

  list.clear(); //清空
  print(list);
}

Map 操作​

Map常用操作：[]、length、keys、values、isEmpty、isNotEmpty、containsKey()、containsValue()、remove()、forEach()等

void main() {
  var map = {'name': 'zs', 'age': 18};
  // Map常用操作
  print(map.length); //2
  print(map.keys); //(name, age)
  print(map.values); //(zs, 18)

  print(map.isEmpty); //false
  print(map.isNotEmpty); //true

  print(map.containsKey('name')); //true
  print(map.containsKey('sex')); //false
  print(map.containsValue('zs')); //true
  print(map.containsValue('ls')); //false

  map.remove('age'); //移除age键值
  print(map);

  map.forEach(f); //传入方法 key=name, value=zs
}

void f(key, value) {
  print("key=$key, value=$value");
}

switch..case 语句​

  • 比较类型：num、String、编译器常量、对象、枚举
  • 非空case必须有一个break
  • default处理默认清空
  • continue跳转标签
void main() {
  // switch..case
  // var a = 1; //1
  // var a = 4; //NULL
  var a = 2; //2 [跳转] 1
  switch (a) {
    D:
    case 1:
      print(1);
      break;
    case 2:
      print(2);
      continue D;
    case 3:
      print(3);
      break;
    default:
      print('NULL');
  }
}

方法定义​

// 语法
返回类型 方法名 (参1, 参2..) {

}
// 【基本使用】

1. 方法也是对象, 并且有具体类型Function
2. 返回值类型、参数类型都可以省略
3. 箭头语法: => expr 是 {return expr} 缩写 [只适用于一个表达式]

可选参数​

1. 可选命名参数: {param1, param2...}
2. 可选位置参数: [param1, param2...]
// 如果存在具体参数，可选参数声明，必须在参数后面
void main() {
  fn1('zs'); //name=zs, age=null, sex=null
  fn1('zs', sex: '男', age: 18); //name=zs, age=18, sex=男

  fn2('ls'); //name=ls, age=null, sex=null
  fn2('ls', '男', 18); //name=ls, age=男, sex=18
  fn2('ls', 18, '男'); //name=ls, age=18, sex=男
}

fn1(name, {age, sex}) {
  print("name=$name, age=$age, sex=$sex");
}

fn2(name, [age, sex]) {
  print("name=$name, age=$age, sex=$sex");
}

//注：可选命名参较常用，传入时无需在意位置关系; 可选位置参，需按顺序传参无法跳过

默认参数值​

在定义方法时可以使用 = 给可选参数指定默认值，默认值只能是编译时常量。

  fn2('ls'); //name=ls, age=保密, sex=保密

fn1(name, {age = '保密', sex = '保密'}) {

}

fn2(name, [age = '保密', sex = '保密']) {

计算属性​

计算属性的值是通过计算而来的，本身不存储值。计算属性赋值，其实是通过计算转换到其他实例变量。

void main() {
  var r = new Rectangle();
  r.width = 10;
  r.height = 10;
  print(r.area); //100

  r.area = 200;
  print(r.width); //20.0
}

class Rectangle {
  num width, height;
  // 计算属性：[返回值类型 get 计算属性名]
  num get area => width * height;
  // 计算属性赋值：计算转换其他变量
  set area(val) {
    width = val / height;
  }
}

工厂构造方法​

工厂构造方法类似于设计模式中的工厂模式。 在构造方法前添加关键字factory实现一个工厂构造方法，方法中可返回对象。

void main() {
  var p = new Person('zs', 20);
  print(p.name); //zs
  print(p.age); //20
}

class Person {
  String name;
  int age;

  // 工厂构造
  factory Person(String name, int age) {
    return Person._p(name, age);
  }

  Person._p(this.name, this.age); //私有构造方法
}

/* 【工厂构造函数的特性】
   工厂构造函数类似于static静态成员,无法访问this指针,所以在工厂构造函数中能处理的任务较为有限。
   使用工厂构造函数时往往需要定义一个命名构造函数用来生产实例。
*/

静态成员​

使用static关键字来实现类级别的变量和函数。 静态成员不能访问非静态成员，非静态成员可以访问静态成员。 类中的常量需要使用static const声明。

void main() {
  var p = new Person();
  Person.sayHi(); //类调用
  p.sayBye(); //对象调用
}

class Person {
  // 类中的常量必须使用static定义
  static const int maxNum = 66;
  // 静态变量
  static int num = 0;
  // 非静态变量
  int num2 = 1;

  // 静态方法，实例不能直接调用,需要类调用
  static void sayHi() {
    num++;
    // num2++; [报错：静态无法访问非静态]
    print('hi');
  }

  void sayBye() {
    num--; //非静态可以访问静态
    print('bye');
  }
}

面向对象扩展​

继承​

  • 使用关键字extends继承一个类，super引用父类
  • 子类会继承父类可见的属性和方法，不和继承构造方法
  • 子类能重写父类的方法，getter和setter方法
  • 单继承，多态性
void main() {
  var son = new Son();
  son.name = 'zs';
  son.age = 18;
  print(son.flag); //true
  son.study(); //learning..2

  // 类型为Father,值为Son实例
  Father father = new Son();
  // father.sayS(); //[报错：因为给的类型是Father]
  father.study(); //learning..2
  print(father is Son); //true
  print(father is Father); //true
}

//子类
class Son extends Father {
  @override //覆盖
  // bool get flag => super.flag;
  bool get flag => age > 16;

  void sayS() {
    print('Son');
  }

  @override
  void study() {
    print('learning..2');
  }
}

//父类
class Father {
  String name;
  int age;

  bool get flag => age > 18;

  void sayF() {
    print('Father');
  }

  void study() {
    print('learning..1');
  }
}

继承中的构造方法​

  • 子类的构造方法默认会调用父类的无名无参构造方法
  • 如果父类没有无名无参构造方法，则需要显示调用父类构造方法
  • 在构造方法参数后使用：显示调用父类构造方法
  • 构造方法执行顺序：
    • 父类的构造方法在子类构造方法体开始执行的位置调用
    • 如果有初始化列表，初始化列表会在父类构造方法之前执行
void main() {
  var son = new Son(); //Father [默认调用无名无参]
}

class Son extends Father {}

class Father {
  Father() {
    print('Father');
  }
}
void main() {
  var son = new Son('zs', 20);
  print(son.age); //20
}

class Son extends Father {
  final int age;

  // 显示调用父类构造方法
  // Son(String name) : super.withName(name); //调用有名有参
  Son(String name, int ag)
      : age = ag,
        super.withName(name); //初始化列表[置于前] + 调用有名有参
}

class Father {
  String name;
	//父类构造方法
  Father(this.name);
  Father.withName(this.name);
}

抽象类​

  • 抽象类通过abstract关键字来创建，抽象类不能通过new实例化
  • 抽象方法不用abstract修饰，抽象类方法可以没有，也可以为空
  • 通过子类继承抽象类来实现抽象类的方法和属性
  • 有抽象方法的类一定要声明为抽象类
void main() {
  var stu = new Student();
  stu.run(); //重写抽象类的方法
}

abstract class People {
  // 抽象方法可有可无可空
  void run() {}
}

// 继承抽象类属性和方法
class Student extends People {
  void run() {
    print('重写抽象类的方法');
  }
}

接口​

  • 类和接口是统一的，类就是接口
  • 每个类都隐式的定义了一个包含所有实例成员的接口
  • 如果是复用已有类的实现(父类都写好了)，使用继承(extends)
  • 如果只是使用已有类的外在行为，使用接口(implements)
  • 使用接口，需要重写类的所有属性和方法
void main() {
  var stu = new Student();
  stu.run();
}

abstract class People {
  String name;
  // 抽象方法可有可无可空
  void run() {}
}

// 继承抽象类属性和方法
class Student implements People {
  // 接口 需要重写属性和方法
  @override
  String name;

  @override
  void run() {
    print('重写抽象类的方法');
  }
}

Mixins​

  • Mixins类似于多继承，是在多继承中重用一个类代码的方式
  • 作为Mixin的类不能有显示声明构造方法
  • 作为Mixin的类只能继承自Object(默认继承)，不能是继承其他类的子类
    • 使用关键字with连接一个或多个
void main() {
  var d = new D();
  d.d(); //D-d
  d.a(); //C-a 注：多个类中有相同的方法，调用的是最后一个类方法
}

class A {
  void a() {
    print('A-a');
  }
}

class B {
  void a() {
    print('B-a');
  }

  void b() {
    print('B-b');
  }
}

class C {
  void a() {
    print('C-a');
  }

  void c() {
    print('C-c');
  }
}

// Mixins语法：使用关键字with连接mixins
class D extends A with B, C {
  void d() {
    print('D-d');
  }
}
// 案例
void main() {
  var car = new Car();
  var bus = new Bus();
  car.work(); //烧电引擎
  bus.work(); //烧油引擎
}

abstract class Engine {
  void work();
}

class OilEngine implements Engine {
  void work() {
    print('烧油引擎');
  }
}

class ElectricEngine implements Engine {
  void work() {
    print('烧电引擎');
  }
}

class Tyre{
  String name;
  void run() {
    print('跑起来啦');
  }
}

class Car = Tyre with ElectricEngine;
class Bus = Tyre with OilEngine;
// 不同的写法：class Car extends Tyre with OilEngine{}

// 语法
返回类型 operator 操作符 (参数1, 参数2){
  实现体..
  return 返回值
}

// 注：如果覆写==，还需要覆写对象的hashCode getter方法
可覆写操作符​
<     >    <=   >=   ==
+     -    *    /    %   ~/
&     |    ^    <<   >>
[]   []=   ~
案例​
void main() {
  var p1 = new Person(18);
  var p2 = new Person(18);
  print(p1 == p2); //true
  print(p2['num']); //404
  print(p2['age']); //18
}

class Person {
  int age;
  Person(this.age);

  // 1.覆写== 还需覆写hashCode[getter]
  @override
  bool operator ==(Object other) {
    return identical(this, other) ||
        other is Person && runtimeType == other.runtimeType && age == other.age;
  }

  @override
  int get hashCode => age.hashCode;

  // 2.覆写[]
  int operator [](String str) {
    if ("age" == str) {
      return age;
    }
    return 404;
  }

  // 3.noSuchMethod()：当代码试图调用不存在的方法或者实例变量，可以覆盖noSuchMethod()来检测或响应
  @override
  void noSuchMethod(Invocation invocation) {
    print("You tried to use a non-existent member：$invocation.memberName");
  }
}

枚举​

枚举是一种有穷序列集的数据类型，使用关键字enum定义一个枚举，常用于代替常量，控制语句等。

// 枚举特性
1. index从0开始，依次累加
2. 不能指定原始值
3. 不能添加方法
void main() {
  var currentSeason = Season.autumn; //7-9月
  // index从0开始
  print(Season.spring.index); //0
  print(Season.summer.index); //1
  print(Season.autumn.index); //2
  print(Season.winter.index); //3
  switch (currentSeason) {
    case Season.spring:
      print('1-3月');
      break;
    case Season.summer:
      print('4-6月');
      break;
    case Season.autumn:
      print('7-9月');
      break;
    case Season.winter:
      print('10-12月');
      break;
  }
}

// enum定义枚举 不能赋值不能存方法
enum Season { spring, summer, autumn, winter }

泛型​

Dart中类型是可选的，可使用泛型限定类型。使用泛型能有效的减少代码重复。 

void main() {
  // dart中类型是可选的，可使用泛型限定类型
  var list = new List<int>(); //限定int
  list.add(1);
  // list.add("1"); [报错]
  print(list); //[1]
}

类的泛型​

void main() {
  // 类的泛型
  var units = new Units<int>();
  units.say(6); //6
  // units.say("6"); [报错]
}

class Units<T> {
  void say(T ele) {
    print(ele);
  }
}

方法的泛型​

void main() {
  // 方法的泛型
  var units = new Units();
  units.say<int>(6); //6
  units.say<String>("6"); //6
}

class Units {
  void say<T>(T ele) {
    print(ele);
  }
}
