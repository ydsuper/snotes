治愈系英语

学前须知​

口语练习标准​

  • 基础方法

    假设当前目标是10句话，一开始不要直接从上到下泛读，先单句话精读，再3-5句话分组循环精读。

  • 车轮方法

    假设目标是几十句话，先用基础方法训练后，到了输出过程中间遇到了最卡顿的语句，利用车轮法：在上下各选择2句话，组成5句话，循环训练这5句话，从最卡顿 → 最顺。

  • 呼吸法（高级）

    深吸一口气后，开始练习，一口气的时间保证速度和清晰度的情况下尽更可能多的练习（平均20-30s）。熟练时可以保证一口气不断，否则则代表语句还不够熟练掌握。该方法结合应用到基础与车轮方法中。
