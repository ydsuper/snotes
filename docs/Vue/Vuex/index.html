Vuex

文档

VueX 概述​

Vuex 是一个专为 Vue.js 应用程序开发的状态管理模式。它采用集中式存储管理应用的所有组件的状态，并以相应的规则保证状态以一种可预测的方式发生变化。Vuex 也集成到 Vue 的官方调试工具 devtools extension ，提供了诸如零配置的 time-travel 调试、状态快照导入导出等高级调试功能。

什么情况下使用

Vuex可以帮助我们管理共享状态，并附带了更多的概念和框架。这需要对短期和长期效益进行权衡。

如果您不打算开发大型单页应用，使用 Vuex 可能是繁琐冗余的。确实是如此——如果您的应用够简单，您最好不要使用 Vuex。一个简单的 store 模式就足够您所需了。但是，如果您需要构建一个中大型单页应用，您很可能会考虑如何更好地在组件外部管理状态，Vuex 将会成为自然而然的选择。引用 Redux 的作者 Dan Abramov 的话说就是：

Flux 架构就像眼镜：您自会知道什么时候需要它。

VueX 基本使用​

每一个 Vuex 应用的核心就是 store（仓库）。"store"基本上就是一个容器，它包含着你的应用中大部分的状态 (state)。Vuex 和单纯的全局对象有以下两点不同：

  • Vuex 的状态存储是响应式的。当 Vue 组件从 store 中读取状态的时候，若 store 中的状态发生变化，那么相应的组件也会相应地得到高效更新。
  • 你不能直接改变 store 中的状态。改变 store 中的状态的唯一途径就是显式地提交 (commit) mutation。这样使得我们可以方便地跟踪每一个状态的变化，从而让我们能够实现一些工具帮助我们更好地了解我们的应用。

安装​

# [方式一] 直接下载 / CDN引用
# [方式二] npm / yarn
  npm install vuex --save
  yarn add vuex

配置​

// [引入vuex]
import { createStore } from "vuex";

// 配置 [导出]
export default createStore({
  // 存数据 state状态
  state() {
    return {};
  },

  // 用于修改Store中的数据 [同步方法]
  mutations: {},
  // 处理异步任务 [异步方法]
  actions: {},
  // getter [相当于computed]
  getters: {},
});

挂载​

import { createApp } from "vue";
import App from "./App.vue";
import store from "./store"; //引入store

createApp(App)
  .use(store) //挂载store
  .mount("#app");

VueX 核心概念​

State​

存储在 Vuex 中的数据和 Vue 实例中的 data 遵循相同的规则，例如状态对象必须是纯粹 (plain) 的。

#store
import { createStore } from "vuex";
export default createStore({
    // 类似于vue中的data
    state() {
        return {
            name: "张嘎",
            age: "18",
            list: ['天', '下', '第', '一', '键']
        }
    },
    mutations: {},
    actions: {},
    getters: {}
})
&component
<template>
  <div>
    <h1>vuex-state</h1>
    <h3>我是{{ name }}，今年{{ age }}岁</h3>
    <ul>
      <li v-for="item in list" :key="item.id">{{ item }}</li>
    </ul>
  </div>
</template>

<script>
import { mapState } from "vuex"; //引入mapState方法
export default {
  name: "HelloVuex",
  data() {},
  computed: {
    // 获取state的数据值
    // 【方式一】this.$store.state.属性名
    // name() {
    //   return this.$store.state.name;
    // },
    // age() {
    //   return this.$store.state.age;
    // }

    // 【方式二】mapState
    ...mapState(["name", "age", "list"]),
  },
};
</script>

Getters​

#store
import { createStore } from "vuex";
export default createStore({
    state() {
        return {
            // 1.声明数据
            count: 0,
            count2: 0
        }
    },
    mutations: {
        add(state) {
            state.count++;
        },
        add2(state) {
            state.count2++;
        }
    },
    actions: {},
    getters: {
        // 2.让数据变化
        // 3.数据变化后 同步更新
        num(state) {
            return state.count;
        },
        num2(state) {
            return state.count2;
        }
    }
})
&component
<template>
  <div>
    <h1>vuex-state</h1>
    <button @click="add">【方一】数字自增：{{ num1 }}</button>
    <button @click="add2">【方二】数字自增：{{ num2 }}</button>
  </div>
</template>

<script>
import { mapMutations, mapGetters } from "vuex";
export default {
  name: "HelloVuex",
  methods: {
    ...mapMutations(["add", "add2"]),
  },
  computed: {
    // 【方式一】this.$store.getters.属性名
    num1() {
      return this.$store.getters.num;
    },

    // 【方式二】
    ...mapGetters(["num2"]),
  },
};
</script>

Mutations​

只能执行同步代码，类似ajax、定时器不能在mutations中执行

#store
import { createStore } from "vuex";
export default createStore({
    state() {
        return {
            name: "张三(初始name)",
            name2: "张三(初始name)"
        }
    },
    mutations: {
        // 通过state参数获取state中的数据
        // 未传参
        changeName(state) {
            state.name = "李四(未传参修改)"
        },
        // 传参
        changeOtherName(state, aname) {
            state.name2 = aname;
        }
    },
    actions: {},
    getters: {}
})
&component
<template>
  <div>
    <h1>vuex-mutation</h1>

    <h3 @click="handleChange">Name：{{ name }}</h3>
    <h3 @click="handleOtherChange">Name：{{ name2 }}</h3>

    <h2>使用mapMutations方法修改</h2>
    <h3 @click="changeName">Name：{{ name }}</h3>
    <h3 @click="changeOtherName(dataName)">Name：{{ name2 }}</h3>
  </div>
</template>

<script>
import { mapState, mapMutations } from "vuex"; //引入mapMutations方法
export default {
  name: "HelloVuex",
  data() {
    return {
      dataName: "李四(传参修改)",
    };
  },
  methods: {
    // 【方式一】this.$store.commit触发mutations中的方法
    // [未传参]
    handleChange() {
      this.$store.commit("changeName");
    },
    // [传参]
    handleOtherChange() {
      this.$store.commit("changeOtherName", this.dataName);
    },

    // 【方式二】
    ...mapMutations(["changeName", "changeOtherName"]),
  },
  computed: {
    ...mapState(["name", "name2"]),
  },
};
</script>

Acions​

执行异步代码，然后将数据交给mutations才能完成

#store
import { createStore } from "vuex";
export default createStore({
    state() {
        return {
            count: 0,
            count2: 0
        }
    },
    mutations: {
        add(state, val) {
            state.count += val;
        },
        add2(state, val) {
            state.count2 += val;
        }
    },
    // 异步任务处理
    actions: {
        // context代表上下文 可以获取使用state、mutations、getters等
        asyncAdd(context, val) {
            console.log(context);
            setInterval(function () {
                // 调用同步方法
                context.commit('add', val);
            }, 1000);
        },
        asyncAdd2(context, val) {
            console.log(context);
            setInterval(function () {
                context.commit('add2', val);
            }, 1000);
        }
    },
    getters: {}
})
&component
<template>
  <div>
    <h1>vuex-action</h1>

    <button @click="add(1)">【方式一】</button>
    <h3>{{ count }}</h3>
    <button @click="asyncAdd2(2)">【方式二】</button>
    <h3>{{ count2 }}</h3>
  </div>
</template>

<script>
import { mapState, mapActions } from "vuex";
export default {
  name: "HelloVuex",
  computed: {
    ...mapState(["count", "count2"]),
  },
  methods: {
    // 【方式一】this.$store.dispatch触发actions中的方法
    add(val) {
      this.$store.dispatch("asyncAdd", val);
    },

    // 【方式二】
    ...mapActions(["asyncAdd2"]),
  },
};
</script>

Modules​

#store
import { createStore } from "vuex";

const moduleA = {
    // 为模块开启命名空间
	namespaced:true,
    state() {
        return {
            name1: "张三1"
        }
    },
    mutations: {
        changeName1(state) {
            state.name1 = "张三1(已修改)";
        }
    },
    actions: {},
    getters: {}
}

const moduleB = {
    // 为模块开启命名空间
	namespaced:true,
    state() {
        return {
            name2: "张三2"
        }
    },
    mutations: {
        changeName2(state) {
            state.name2 = "张三2(已修改)";
        }
    },
    actions: {},
    getters: {}
}

export default createStore({
    // 导出所有模块
    modules: {
        mA: moduleA,
        mB: moduleB
    }
})
&component
<template>
  <div>
    <h1>vuex-module</h1>
    <button @click="changeName1(), changeName2()">修改</button>
    <h3>我是{{ mA.name1 }}</h3>
    <h3>我是{{ mB.name2 }}</h3>
  </div>
</template>

<script>
import { mapState, mapMutations } from "vuex"; //引入mapState方法
export default {
  name: "HelloVuex",
  methods: {
    ...mapMutations(["changeName1", "changeName2"]),
  },
  computed: {
    ...mapState(["mA", "mB"]),
  },
};
</script>
