上面代码，我们使用 isNaN 来测试后，发现字符串，undefined，甚至对象，结果都返回真！！！但是他们不是 NaN。

break 和 continue​

在switch或者循环过程中，我们总是满足布尔表达条件才能执行对应的代 码，然而在这些逻辑过程中，可以使用一些关键字直接跳出正在执行的代 码，去执行后边或者指定位置的代码，这些关键字一旦出现就可以跳转语 句执行顺序。

  • break

    用法：无法单独使用，必须将break关键字置于switch或循环语句中执行过中，不需要判断任何条件，只要遇到break便直接跳出执行后续代码，会完全跳出选择或者循环结构。break只能跳出最近的代码块，不能跨越多级代码块。

    for (i = 0; i < 10; i++) {
      if (i == 3) {
        break;
      }
      var x = "The number is " + i;
      console.log(x);
    }
    //由于这个 if 语句只有一行代码，所以可以省略花括号：
    for (i = 0; i < 10; i++) {
      if (i == 3) break;
      var x = "The number is " + i;
      console.log(x);
    }

  • continue

    用法：无法单独使用，必须将continue关键字置于循环语句中。 不需要判断任何条件，只要遇到continue便直接跳出本轮循环进行 下次循环，继续循环中的下一个迭代。

    for (i = 0; i <= 5; i++) {
      if (i == 3) continue; //if语句只有一行代码，可以省略花括号
      var x = "The number is " + i;
      console.log(x);
    }

数组介绍​

​ 在现实业务中，我们经常要操作多个相似数据，假如你有一个超大型的车库，里面放着300辆豪车，某天你要从中提出某一辆对你有特殊意义的车，这将不是一件容易的事！最好的方法就是用数组。数组可以用一个变量名存储所有的值，并且可以用变量名访问任何一个值。数组中的每个元素都有自己的的ID，以便它可以很容易地被访问到。所以，针对多个相似的数据，我们可以定义一个数组，将多个相似数据直接存储到这个数组中，集中处理数据。数组对象是使用单独的变量名来存储一系列的值。数组是存储多个变量(元素)的容器，这多个变量的数据类型要一致。(数组是最基本的，也是运算速度最快的数据容器)

数组的遍历​

​ 遍历数组是最常见的操作，即依次访问数组中的每个元素。定义一个变量 i 作为索引，以跟踪访问的位置，使用 数组名.length 可以获取数组长度，条件就是 i 不能超过 length，配合循环可以完成遍历动作。

//格式：

  console.log(数组名[i]);
}
var arr = [11, 22, 33, 44, 55];
for (var i = 0; i < arr.length; i++) {
  console.log(arr[i]); // 11  22  33  44  55
}

作用域​

  • 函数作用域 (局部作用域)

    • 函数作用域：声明在函数内的变量、函数 拥有函数作用域

This 指向​

this 是 JavaScript 语言的一个关键字，它是函数运行时，在函数体内部自动生成的一个对象，只能在函数体内部使用。

那么，this 的值是什么呢？

函数的不同使用场合，this 有不同的值。总的来说，this 就是函数运行时所在的环境对象。

下面分四种情况，详细讨论 this 的用法。

在浏览器中this的指向（对象）​

  • 单纯的函数中，this指向 window 对象

    function fn() {
      console.log(this);
    }
    fn(); //window

  • 在对象中，如果this在对象的方法中，那么this指向该对象

    let obj = {
      sayHi: function fn() {
        console.log(this);
      },
    };
    obj.sayHi(); // Object

  • 在构造函数中，this 指向的是创建( new )出来的对象

    let Person = function (name) {
      console.log(this); // Person
      this.name = name;
      this.fn = function () {
        console.log(this); // Person
      };
    };
    let zs = new Person("zs");
    console.log(zs);
    zs.fn(); // Person

  • 如果使用 call 或 apply 改变 this 的指向，那么 this 指向的是 call 的第一个参数对象；this 指向的是 apply 的第一个参数对象

    // 定义一个小苹果
    let apple = {
      size: "small",
      say: function () {
        console.log(`Size is ${this.size}`);
      },
    };
    apple.say(); // Size is small
    // 定义一个大橙子
    let orange = {
      size: "big",
    };
    //  我们使用apply和call来改变this的指向
    //  apply是立即执行的 不需要调用
    apple.say.apply(orange); // Size is big
    //  call也是立即执行的 不需要调用
    apple.say.call(orange); //  Size is big
apply 和 call方法的使用​

为什么要学习apply 和call ，因为在某些时候，我们需要在一个方法中调用另外一个对象的属性。call 和 apply 都是为了改变某个函数运行时的上下文（context）而存在的，换句话说，就是为了改变函数体内部 this 的指向。

apply()调用​
  • apply() 是函数的一个方法，作用是：改变函数的调用对象。 括号内第一个参数表示这个函数改变后调用的对象。因此，这时 this 指的就是这第一个参数。
call()调用​
  • 作用和 apply 的作用一样
apply 和 call 方法的区别​

apply 的语法：

函数.apply (要指向哪个对象, [ 该函数的参数 1,该函数的参数 2,.... ])​

call 的语法：

函数.call (要指向哪个对象, 该函数的参数 1,该函数的参数 2,....)​

SO：对于 apply、call 二者而言，作用完全一样，只是接受参数的方式不太一样

​ call 需要把参数按顺序传递进去，而 apply 则是把参数放在数组里。 当你的参数是明确知道数量时用 call ，而不确定的时候用 apply，然后把参数 push 进数组传递进去。当参数数量不确定时，函数内部也可以通过 arguments 这个伪数组来遍历所有的参数。

小结​

  • ① call 和 apply 都是用来调用函数，而且是立即调用

  • ② 如果第一个参数指定了 null 或者 undefined 则内部 this 指向 window

  • ③ 但是可以在调用函数的同时，通过第一个参数指定函数内部 this 的指向

  • ④ call 调用的时候，参数必须以参数列表的形式进行传递，也就是以逗号分隔的方式依次传递即可

  • ⑤ apply 调用的时候，参数必须是一个数组，然后在执行的时候，会将数组内部的元素一个一个拿出来，与形参一一对应进行传递

bind 方法​

bind() 方法与 apply 和 call 很相似，也是可以改变函数体内 this 的指向。

  • MDN的解释是：bind()方法会创建一个新函数，称为绑定函数，当调用这个绑定函数时，绑定函数会以创建它时传入 bind()方法的第一个参数作为 this，传入 bind() 方法的第二个以及以后的参数加上绑定函数运行时本身的参数按照顺序作为原函数的参数来调用原函数。​
bind 和 call、apply 的区别​

bind 不会立即调用 ，需要手动调用 bind 的参数列表和 call 一样

格式：函数.bind(this 指向的对象, 参数, 参数...)

如果 复制出来的函数 还传参 那么会把两组参数进行叠加

var obj = {
  x: 81,
};
var foo = {
  getX: function () {
    return this.x;
  },
};
console.log(foo.getX.bind(obj)()); //81
console.log(foo.getX.call(obj)); //81
console.log(foo.getX.apply(obj)); //81
/*   三个输出的都是81，但是注意看使用 bind() 方法的，他后面多了对括号。
   也就是说，当你希望改变上下文环境之后并非立即执行，而是回调执行的时候，使用 bind() 方法，而 apply或call 则会立即执行函数。                                  */
总结​

  • ①apply、 call、 bind 三者都是用来改变函数的 this 对象的指向的；

  • ②apply、 call、 bind 三者第一个参数都是 this 要指向的对象， 也就是想指定的上下文；

  • ③apply、 call、 bind 三者都可以利用后续参数传参；

  • ④bind 是返回对应函数， 便于稍后调用； apply、 call 则是立即调用。

变量属性函数方法四者的区别​

属性是对象的一部分，而变量不是对象的一部分，变量是单独存储数据的容器

变量：单独声明赋值，单独存在

属性：对象里面的变量称为属性，不需要声明，用来描述该对象的特征

方法是对象的一部分，函数不是对象的一部分，函数是单独封装操作的容器

函数：单独存在的，通过“函数名()”的方式就可以调用

方法：对象里面的函数称为方法，方法不需要声明，使用“对象.方法名()”的方式就可以调用，方法用来描述该对象的行为和功能。

Map 集合​

Map是一组键值对的结构，具有极快的查找速度。Map是无序集合

Map 的属性和方法​
  1. 属性​
    • size：返回字典所包含的键值对个数 字典名.size
  2. 方法​

    • set(key, val)：向字典中添加新元素

      字典名.set(键的名字,值的名字)给字典添加成员键值对 返回新的

    • get(key)：通过键值查找特定的数值并返回

      字典名.get(key)通过key获取map的key对应的值

    • has(key)：如果键存在字典中返回 true,否则 false 字典名.has(键) 判断键是否在字典内，在就返回ture，不在返回false

    • delete(key)：通过键值从字典中移除对应的数据

      字典名.delete(键) 通过键删除字典中对应的那条数据

    • clear()：将这个字典中的所有元素删除

      字典名.clear() 无参数，清除所有成员数据，返回值undefined

  3. 遍历方法

    • keys()：将字典中包含的所有键名以数组形式返回 （遍历键）

      let map = new Map([
        ["name", "zd"],
        ["age", 66],
      ]);
      for (let key of map.keys()) {
        console.log(key); // name  age
      }

    • values()：将字典中包含的所有数值以数组形式返回 （遍历值）

      let map = new Map([
        ["name", "zd"],
        ["age", 66],
      ]);
      for (let value of map.values()) {
        console.log(value); // zd  66
      }

    • entries()：返回键值对的对象 （遍历键值对）

      let map = new Map([
        ["name", "zd"],
        ["age", 66],
      ]);
      for (let item of map.entries()) {
        console.log(item[0] + "=>" + item[1]);
        //  name=>zd  age=>66
      }

    • forEach()：遍历字典的所有成员

      let map = new Map([
        ["name", "zd"],
        ["age", 66],
      ]);
      map.forEach(function (value, key, map) {
        console.log(key, value, map);
      });

      //  name zd  Map{ 'name' => 'zd', 'age' => 66 }
      //  age  66  Map{ 'name' => 'zd', 'age' => 66 }

遍历数组的全部方法

ForEach 语句​

forEach 方法对数组的每个元素执行一次提供的回调函数，forEach是一个数组方法，可以用来把一个函数套用在一个数组中的每个元素上，forEach为每个数组元素执行callback函数只可用于数组。遍历一个数组让数组每个元素做一件事情. 数组自带的foreach循环，使用频率较高，实际上性能比普通for循环弱。

var arr = ["A", "B", "C"];
arr.forEach(function (item, key) {
  console.log(key + ":" + item);
}); // 0:A  1:B  2:C
For-in 语句​

一般会使用for-in来遍历对象的属性的，不过属性需要 可枚举性，才能被读取到。for-in 循环只遍历可枚举属性。一般常用来遍历对象，包括非整数类型的名称和继承的那些原型链上面的属性也能被遍历。像和的不可枚举属性就不能遍历了

let obj = {
  name: "G",
  age: 18,
  sex: "男",
};
for (let key in obj) {
  console.log(key, obj[key]);
} // name G  age 18  sex 男
For-of 语句​

for-of语句在可迭代对象（包括 Array，Map，Set，String，TypedArray，arguments 对象等等）上创建一个迭代循环，调用自定义迭代钩子，并为每个不同属性的值执行语句。只要是一个iterable的对象，就可以通过for-of来迭代。

let arr = [
  {
    name: "G",
  },
  666,
  "love",
];
for (let item of arr) {
  console.log(item);
} // { name: 'G' }  666  love
for-of 和 for-in 的区别​

for-in 语句以原始插入顺序迭代对象的可枚举属性。for-in会把继承链的对象属性都会遍历一遍，所以会更花时间。for-of 语句只遍历可迭代对象的数据。

数组的扩展

  • 数组实例的 entries( )、keys( )、values( )​

    ES6 提供三个新的方法 —— entries()、keys()、values() —— 用于遍历数组。它们都返回一个遍历器对象，可以用for...of循环进行遍历，唯一的区别是keys()是对键名的遍历、values()是对键值的遍历，entries()是对键值对的遍历

  • 扩展运算符​

    扩展运算符是三个点（...）。它好比 rest 参数的逆运算，将一个数组转为用逗号分隔的参数序列。

    let arr = [1, 2, 3];
    console.log(...arr);// 1 2 3
    // 作用1: 拓展运算符连接数组
    let arr1 = [1, 2, 3];
    let arr2 = ['a', 'b', 'c'];
    let arr3 = [...arr1, ...arr2];
    console.log(arr3);// [ 1, 2, 3, 'a', 'b', 'c' ]
    /该运算符主要用于函数调用。
    var array = [1, 2]
    function push(array, ...rest) {
      array.push(...rest);
    }
    push(array, ...[4, 5]);
    console.log(array); // (4) [ 1, 2, 4, 5 ]
    push(array, [4, 5]);
    console.log(array); // (3) [ 1, 2, [ 4, 5 ] ]
    /扩展运算符后面还可以放置表达式。
    var x = 5;
    const arr = [
        ...(x > 0 ? ['a'] : []),
        'b',
    ];
    console.log(arr); // (2) ["a", "b"]
    如果扩展运算符后面是一个空数组，则不产生任何效果。
    [...[], 1]
    console.log([...[], 1]); // [ 1 ]

    // ES5 的写法

    var args = [0, 1, 2];

    }
    let args = [0, 1, 2];
    f(...args);   // 0 1 2
