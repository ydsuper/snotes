面向过程和面向对象对比​

ES6 中的类和对象​

对象​

"万物皆对象"，对象是一个具体的事物 在JavaScript中，对象是一组无序的相关属性和方法的集合，所有的事物都是对象，如字符串数值数组函数等。

对象是由属性和方法组成的：

  • 属性：事物的特征，在对象中用属性来表示（常用名词）
  • 方法：事物的行为，在对象中用方法来表示（常用动词）

类​

在ES6中新增了类的概念，可使用class关键字声明一个类，之后以这个类实例化对象。 类抽象了对象的公共部分，它泛指某一大类; 对象特指某一个，通过类实例化一个具体的对象。

// 面向对象的思维特点：
1. 抽取(抽象)对象共用的属性和行为组织(封装)成一个类(模板)
2. 对类进行实例化，获取类的对象

创建类​

// 语法
class 类名 { }
// 创建实例
let obj = new 类名();

/注：类必需使用new实例化对象

constructor 构造函数​

constructor()方法是类的构造函数(默认方法)，用于传递参数、返回实例对象，通过new生成对象实例时，自动调用该方法，如果没显示定义，类内部会自动创建一个constructor()

class 类名 {
    constructor(共有属性1, 共有属性2...){ //constructor构造器存放共有属性
        this.属性1 = 属性1;
        this.属性2 = 属性2;
        ...
    }
}

添加共有方法​

class Person {
  constructor(name, age) {
    this.name = name;
    this.age = age;
  }
  say() {
    //声明方法
    console.log("我是" + this.name + "今年" + this.age);
  }
}
let man = new Person("张三", 18);
man.say(); //我是张三今年18

注意点​

  • 通过 class 关键字创建类， 类名还是习惯性定义首字母大写
  • 类里面有个 constructor 函数，可以接收传递过来的参数，同时返回实例对象
  • constructor 函数 只要 new 生成实例时，就会自动调用这个函数, 如果不写这个函数，类也会自动生成这个函数
  • 因为 class 本质是一个函数，所以多个函数方法之间不需要添加逗号分隔
  • 生成实例 new 不能省略
  • 创建类 类名后不带小括号，生成实例 类名后带小括号, 构造函数无需加 function

类的继承​

继承​

"子承父业"，子类继承父类的一些属性和方法。

class Father {
  //父类
  constructor(x, y) {
    this.x = x;
    this.y = y;
  }
  sum() {
    //求和
    console.log(this.x + this.y);
  }
}
class Son extends Father {
  //子类 使用extends继承
}
let son = new Son(1, 2);
son.sum(); //3

spuer 关键字​

super关键字用于访问和调用对象父类上的函数。 可以调用父类上的构造函数，也可以调用父类的普通函数。

class Father {
  //父类
  constructor(x, y) {
    this.x = x;
    this.y = y;
  }
  sum() {
    //求和
    console.log(this.x + this.y);
  }
  say() {
    return "我是Father";
  }
}

class Son extends Father {
  //子类 使用extends继承
  constructor(x, y) {
    super(x, y);
  }
  subtract() {
    console.log(this.x - this.y);
  }
  say() {
    console.log(super.say() + "的Son");
  }
}
let son = new Son(1, 2);
son.sum(); //3
son.subtract(); //-1
son.say(); //我是Father的Son

注意：

  • 继承中的属性或方法查找原则为 就近原则（先查找子类后查找父类）
  • 子类继承父类的方法同时内部扩展自己的方法，super 调用父类的构造函数 必须在子类 this 之前调用

三个注意点​

  • 在 ES6 中类没有变量提升，所以必须先定义类，才能通过类实例化对象
  • 类里面的共有属性和方法一定要加 this 使用
  • 类里面 this 指向问题： constructor 里面的 this 指向实例对象 方法里面的 this 指向这个方法的调用者

面向对象案例​

tab 栏切换​

let that;
class Tab {
  constructor(id) {
    that = this;
    this.main = document.querySelector(id);
    this.tabadd = this.main.querySelector(".tabadd"); //添加按钮
    this.ul = this.main.querySelector(".fisrstnav>ul");
    this.tabscon = this.main.querySelector(".tabscon");
    this.init(); //初始化
  }
  // 初始化功能
  init() {
    // 更新
    this.updateNode();
    // 相关事件绑定
    for (let i = 0; i < this.lis.length; i++) {
      this.lis[i].index = i;
      this.lis[i].onclick = this.toggleTab;
      this.removes[i].onclick = this.removeTab;
      this.spans[i].ondblclick = this.editTab;
      this.sections[i].ondblclick = this.editTab;
    }
    this.tabadd.onclick = this.addTab;
  }
  // 更新功能
  updateNode() {
    this.lis = this.main.querySelectorAll(".fisrstnav li");
    this.sections = this.main.querySelectorAll(".tabscon>section");
    this.removes = this.main.querySelectorAll(".icon-guanbi");
    this.spans = this.ul.querySelectorAll("li>span:first-child");
  }

  // 【切换功能】
  toggleTab() {
    that.clearClass();
    this.className = "liactive";
    that.sections[this.index].className = "conactive";
  }
  // 清除功能
  clearClass() {
    for (let i = 0; i < this.lis.length; i++) {
      this.lis[i].className = "";
      this.sections[i].className = "";
    }
  }

  // 【添加功能】
  addTab() {
    that.clearClass();
    let newLi = `<li class="liactive"><span>新选项卡</span><span class="iconfont icon-guanbi"></span></li>`;
    let newSe = `<section class="conactive">测试${+new Date()}</section>`;
    // insertAdjacentHTML方法
    that.ul.insertAdjacentHTML("beforeend", newLi);
    that.tabscon.insertAdjacentHTML("beforeend", newSe);

    that.init(); //更新
  }

  // 【删除功能】
  removeTab(e) {
    e.stopPropagation(); //阻止冒泡
    let index = this.parentNode.index;
    that.lis[index].remove();
    that.sections[index].remove();
    that.init(); //更新
    if (that.main.querySelector(".liactive")) return;
    index--;
    !that.lis[index] && that.lis.length && that.lis[index + 1].click();
    that.lis[index] && that.lis[index].click();
  }

  // 【编辑功能】
  editTab() {
    // 禁用双击选中
    window.getSelection ? window.getSelection().removeAllRanges() : document.selection.empty(); //是否有选中范围？删除选中:空
    // 切换文本框
    let txt = this.innerHTML;
    this.innerHTML = `<input type='text' value='${txt}'>`;
    let ipt = this.children[0];
    ipt.select(); //选定状态
    // 切换文本
    ipt.onblur = function () {
      this.parentNode.innerHTML = this.value;
    };
    // 回车Enter
    ipt.onkeyup = function (e) {
      if (e.keyCode == 13) {
        this.blur();
      }
    };
    // ipt停止冒泡 解决输入框下双击再次触发span双击事件
    ipt.ondblclick = function (e) {
      e.stopPropagation();
    };
  }
}
new Tab("#tab");

构造函数和原型​

概述​

在典型的OOP的语言中(如Java)，都存在类的概念，类就是对象的模板，对象就是类的实例，但在ES6之前，JS中并没有引入类的概念。 在ES6之前，对象不是基于类创建的，而是用一种称为构建函数的特殊函数来定义对象和它们的特征。

构造函数​

构造函数是一种特殊的函数，主要用来初始化对象，即为对象成员变量赋初始值，它总与new一起使用。可以把对象中一些公共的属性和方法抽取出来，然后封装到该函数里。

new 执行时会执行四部:
1. 在内存中创建一个新的空对象
2. 让this指向这个新对象
3. 执行构造函数里的代码，给这个新对象添加属性和方法
4. 返回这个新对象 (所以构造函数不需要return)

静态成员和实例成员​

JavaScript的构造函数中可以添加一些成员，可以在构造函数本身上添加，也可以在构造函数内部的this上添加。通过这两种方式添加的成员，就分别称为静态成员和实例成员。

  • 静态成员：在构造函数本身上添加的成员称为静态成员,只能由构造函数本身来访问
  • 实例成员：在构造函数内部this创建的成员称为实例成员,只能由实例化的对象来访问
// 【静态成员】：在构造函数上添加的成员
// 【实例成员】：在构造函数内部通过this添加的成员
//构造函数
function Person(uname) {
  this.uname = uname; //实例
}
Person.sex = "♂"; //静态
let obj = new Person("张三", 18);
// 静态成员只能通过构造函数访问 不能通过实例化对象访问
console.log(Person.sex); //♂
console.log(obj.sex); //undefined

// 实例成员只能通过实例化对象访问 不能通过构造函数访问
console.log(obj.uname); //张三
console.log(Person.uname); //undefined

构造函数的问题​

构造函数虽然好用，但是存在浪费内存的问题

function Person(uname, age) {
  this.uname = uname;
  this.age = age;
  this.say = function () {
    console.log("Hi");
  };
}
let obj1 = new Person("张三", 18);
let obj2 = new Person("李四", 20);
// 相同的函数但地址不同 造成了内存浪费
console.log(obj1.say == obj2.say); //false

构造函数原型​

构造函数通过原型分配的函数是所有对象所共享的。 JavaScript规定，每一个构造函数都有一个prototype属性，指向另一个对象。注意这个prototype就是一个对象，这个对象的所有属性和方法，都会被构造函所多拥有。

解决内存浪费问题: 将不变的方法直接定义在prototype对象上，这样实例都可以共享到
function Person(uname, age) {
  this.uname = uname;
  this.age = age;
  // this.say = function () {
  //     console.log('Hi');
  // }
}
// 将方法挂到原型对象上
Person.prototype.say = function () {
  console.log("Hi");
};
let obj1 = new Person("张三", 18);
let obj2 = new Person("李四", 20);
// 方法在原型对象上，实例都可以共享到
console.log(obj1.say === obj2.say); //true

对象原型​

对象都会有一个属性__proto__指向构造函数的prototype原型对象，之所以对象可以使用构造函数prototype原型对象的属性和方法，就是因为对象有__protpo__原型的存在。

1. (__proto__)对象原型和原型对象(prototype)是等价的
2. (__proto__)对象原型的意义在于为对象的查找机制提供一个方向，或者说一条路线，但它是一个非标准属性，因此实际开发中，不可以使用这个属性，它只是内部指向原型对象(prototype)
function Person(uname, age) {
  this.uname = uname;
  this.age = age;
}
let obj = new Person("张三", 18);
// 对象原型 = 原型对象
console.log(obj.__proto__ === Person.prototype); //true

constructor 构造器(函数)​

对象原型(__proto__)和构造函数(prototype)原型对象里面都有一个constructor属性，constructor称为构造器(函数)，因为它指向构造函数本身。

function Person(uname, age) {
  this.uname = uname;
  this.age = age;
}
let obj = new Person("张三", 18);
// 对象原型构造 = 原型对象构造
console.log(obj.__proto__.constructor === Person.prototype.constructor); //true

构造函数实例原型对象关系​

                           构造.prototype
                [构造函数]        ⇌        [原型对象prototype]
                   ↖↘  构造.prototype.constructor  ↗
                     ↖↘                        ↗
 __proto__.constructor ↖↘ new               ↗ 实例.__proto__
                         ↖↘              ↗
                               [对象实例]

原型链​

每一个实例对象又有一个__proto__属性，指向构造函数的原型对象，构造函数的原型对象也是一个对象，也有__proto__属性，这样一层一层往上找就形成了原型链。


                                                              null
                                                             ↗
                          Object原型对象prototype.__proto__ ↗
                                                        ↗
                        Object.prototype             ↗
          [Object构造函数]      ⇌      [Object原型对象prototype]
                Object原型对象.constructor  ↗
                                        ↗
         构造.prototype               ↗
[构造函数]      ⇌      [原型对象prototype]
   ↘  构造.prototype.constructor  ↗
     ↘                        ↗
   new ↘                   ↗ 实例.__proto__
         ↘              ↗
             [对象实例]

原型链查找机制​

- 当访问一个对象的属性(包括方法)时，首先查找这个对象自身有没有该属性
- 如果没有就查找它的原型(也就是__proto__指向的prototype原型对象)
- 如果还没有就查找原型对象的原型(Object的原型对象)
- 依次类推一直找到Object为止(null)
- __proto__对象原型的意义就在于为对象成员查找机制提供一个方向，或者说一条路线
// 对象自身 -> 原型对象 -> Object原型

原型对象中的 this 指向​

1. 在构造函数中，this指向实例对象
2. 在原型对象函数里面的this 也指向实例对象

扩展内置对象方法​

let arr = [1, 2, 3];
// 扩展内置方法 [求和]
Array.prototype.getSum = function () {
  // console.log(this); //this指向调用的数组
  let sum = 0;
  for (let i = 0; i < this.length; i++) {
    sum += this[i];
  }
  return sum;
};
let sum = arr.getSum();
console.log(sum); //6

继承​

ES6之前并没有给我们提供extends继承，我们可以通过构造函数+原型对象模拟实现继承，被称为组合继承。

call()方法​

语法: fn.call(thisArg, arg1, arg2...)
[参数]：
thisArg: 当前调用函数this的指向对象
arg1,arg2: 传递的其他参数
// 作用1：调用函数
function fn() {
  console.log(123);
}
fn(); //123
fn.call(); //123
// 作用2：改变函数this指向
function fn() {
  console.log(this);
}
let obj = {
  name: "zs",
  age: 18,
};
fn.call(); //Window{...}
fn.call(obj); //obj{name: "zs", age: 18}
// 作用3：传递其他参数
function fn(x, y) {
  console.log(x + y);
}
let obj = {
  name: "ls",
  age: 20,
};
fn.call(obj, 1, 2); //3

继承父类型属性和方法​

核心原理：通过call()把父类型的this指向子类型的this，这样就可以实现子类型继承父类的属性。

// 【继承属性】
//构造父类型
function Father(uname, age) {
  this.uname = uname;
  this.age = age;
}
//构造子类型
function Son(uname, age, say) {
  // 让Father的this指向变为Son，并调用Father传入实参
  Father.call(this, uname, age);
  this.say = say;
}
let son = new Son("zs", 18, function () {
  console.log("Hi");
});
console.log(son); //Son{uname: 'zs', age: 18, say: [Function]}
// 【继承方法】
// 构造父类型
function Father(uname, age) {
  this.uname = uname;
  this.age = age;
}
Father.prototype.sayF = function () {
  console.log("我是父级");
};
// 构造子类型
function Son(uname, age, sex) {
  // 让Father的this指向变为Son，并调用Father传入实参
  Father.call(this, uname, age);
  this.sex = sex;
}
// Son.prototype = Father.prototype; //存在问题：导致父级也能调用子级方法
Son.prototype = new Father(); //new一个实例对象(相当于新地址) 就互不影响
Son.prototype.constructor = Son; //指回原构造函数
Son.prototype.sayS = function () {
  console.log("我是子级");
};
let son = new Son("zs", 18, "男");
console.log(son); // Son{uname: "zs", age: 18, sex: "男"}
son.sayF(); //我是父级

类的本质​

1. class 本质还是function
2. 类的所有方法都定义在类的prototype属性上
3. 类创建的实例，里面有__proto__指向类的prototype原型对象
4. ES6的类的绝大部分功能，ES5都可以做到，新的class写法只是让对象原型的写法更加清晰、更像面向对象编程的语法
5. ES6的类其实就是语法糖

PS: 语法糖就是一种便捷写法，简单理解，有两种方法可以实现同样的功能，但是一种写法更加清晰、方便，那么这个方法就是语法糖。

ES5 新增的方法​

迭代(遍历)方法：forEach()、map()、filter()、some()、every()

forEach 方法​

array.forEach(function(currentValue, index, arr){})

[参数]：
currentValue: 必需,当前元素值
index: 可选,当前元素的索引值
arr: 可选,当前元素所属的数组对象

filter 方法​

filter()方法创建一个新的数组，新数组中的元素是符合指定条件的所有元素，主要用于筛选数组

array.filter(function(currentValue, index, arr){})

[参数]：
currentValue: 必需,当前元素值
index: 可选,当前元素的索引值
arr: 可选,当前元素所属的数组对象

`注：直接返回一个新数组`

some 方法​

some()方法用于检测数组中是否有满足指定条件的元素

array.some(function(currentValue, index, arr){})

[参数]：
currentValue: 必需,当前元素值
index: 可选,当前元素的索引值
arr: 可选,当前元素所属的数组对象

`注：返回值是布尔值，有一个满足条件的元素直接返回true，反之false`

严格模式​

严格模式概念​

JavaScript 除了提供正常模式外，还提供了严格模式（strict mode）。ES5 的严格模式是采用具有限制性 JavaScript变体的一种方式，即在严格的条件下运行 JS 代码。 严格模式在 IE10 以上版本的浏览器中才会被支持，旧版本浏览器中会被忽略。

严格模式对正常的 JavaScript 语义做了一些更改：

  1. 消除了 JavaScript 语法的一些不合理、不严谨之处，减少了一些怪异行为。
  2. 消除代码运行的一些不安全之处，保证代码运行的安全。
  3. 提高编译器效率，增加运行速度。
  4. 禁用了在 ECMAScript 的未来版本中可能会定义的一些语法，为未来新版本的 Javascript 做好铺垫。比如一些保留字如：class,enum,export, extends, import, super 不能做变量名

严格模式可以应用到整个脚本或个别函数中。因此在使用时，我们可以将严格模式分为 为脚本开启严格模式 和 为函数开启严格模式 两种情况。

// 深拷贝：深拷贝拷贝多层，每一级别的数据都会拷贝
let obj = {
    name: 'zs',
    age: 18,
    msg: {
        num: 666
    },
    color: ['red', 'blue']
}
let newObj = {};

function deepCopy(newObj, oldObj) {
    for (let k in oldObj) {
        // 判断属性值是否属于数组(注:先判断数组因为数组也属于对象)
        if (oldObj[k] instanceof Array) {
            newObj[k] = [];
            deepCopy(newObj[k], oldObj[k]); //利用递归
        }
        // 判断属性值是否属于对象
        else if (oldObj[k] instanceof Object) {
            newObj[k] = {};
            deepCopy(newObj[k], oldObj[k]); //利用递归
        } else {
            newObj[k] = oldObj[k];
        }
    }
    return newObj;
}
let copy = deepCopy(newObj, obj);
obj.msg.num = 100;
obj.color.push('pink'); //不会影响拷贝后的数组
console.log(copy); //{ name: 'zs', age: 18, msg: {num: 666}, color: ['red', 'blue'] }

正则表达式​

正则表达式概述​

正则表达式(Regular Expression)是用于匹配字符串中字符组合的模式。在JavaScript中， 正则表达式也是对象。

正则表通常被用来检索、替换那些符合某个模式（规则）的文本.
例如: [验证表单] 用户名表单只能输入英文字母、数字或者下划线,昵称输入框中可以输入中文(匹配). 此外,正则表达式还常用于过滤掉页面内容中的一些敏感词(替换),或从字符串中获取我们想要的特定部分(提取)等.

其他语言也会使用正则表达式，本阶段我们主要是利用JavaScript 正则表达式完成表单验证。

正则表达式的特点​

1. 灵活性、逻辑性和功能性非常的强
2. 可以迅速地用极简单的方式达到字符串的复杂控制
3. 对于刚接触的人来说,比较晦涩难懂。比如: ^\w+([-+.]\w+)*@\w+([-.]\w+)*\.\w+([-.]\w+)*$
4. 实际开发,一般都是直接复制写好的正则表达式.但是要求会使用正则表达式并且根据实际情况修改正则表达式
   比如用户名: /^[a-z0-9_-]{3,16}$/

字符类​

字符类表示有一系列字符可供选择，只要匹配其中一个就可以了。所有可供选择的字符都放在方括号内。

量词符用来设定某个模式出现的次数。

预定义类指的是某些常见模式的简写方式。

        this.nextElementSibling.innerHTML = '<i class="error_icon"></i> 格式输入不正确，请重新输入';
      }
    };
  }

  // 【确认密码】
  surepwd.onblur = function () {
    if (regpwd.test(this.value) && this.value == pwd.value) {
      this.nextElementSibling.className = "success";
      this.nextElementSibling.innerHTML = '<i class="success_icon"></i> 恭喜您输入正确';
    } else {
      this.nextElementSibling.className = "error";
      this.nextElementSibling.innerHTML = '<i class="error_icon"></i> 格式输入不正确，请重新输入';
    }
  };
});
