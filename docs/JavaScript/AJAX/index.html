AJAX

传统网站中存在的问题
 • 网速慢的情况，页面加载时间长，需要等待
 • 表单提交后，如果一项内容不合格，需要重新填写所有表单内容
 • 页面跳转，重新加载页面，造成资源浪费，增加用户等待时间

Ajax 概述​

Ajax是浏览器提供的一套方法，可以实现页面无刷新更新数据（局部刷新），提高用户浏览网站应用的体验。

Ajax运行环境: Ajax技术需要运行在网站环境中才能生效，可使用Node创建的服务器作为网站服务器

Ajax 运行原理及实现​

Ajax 运行原理​

Ajax 相当于浏览器发送请求与接收响应的代理人，以实现在不影响用户浏览页面的情况下，局部更新页面数据，从而提高用户体验。

                     创建          请求
            浏览器端  ---->  Ajax  ---->  服务器端
            浏览器端  <----  Ajax  <----  服务器端
                     响应          响应
                       [开发人员可控]

获取服务器端的响应​

Ajax 状态码​

在创建ajax对象，配置ajax对象，发送请求，以及接收完服务器端响应数据，这个过程中的每一个步骤都会对应一个数值，这个数值就是ajax状态码。

xhr.readyState // 获取Ajax状态码
readyState五个值：
0: 请求未初始化（未调用open()）
1: 服务器连接已建立
2: 请求已接收，接收到了响应头
3: 请求处理中，正在下载响应体
4: 请求已完成，且响应已就绪

onreadystatechage 事件​

当 Ajax 状态码发生变化时将自动触发该事件

// 当Ajax状态码发生变化时
xhr.onreadystatechange = function () {
  // 判断当Ajax状态码为4时
  if (xhr.readyState == 4) {
    // 获取服务器端的响应数据
    console.log(xhr.responseText);
  }
};

两种获取服务器端响应方式的区别​

'区别描述'            'onload事件'      'onreadystatechange事件'
 是否兼容IE低版本         不兼容                 兼容
 是否需判断Ajax状态码     不需要                 需要
 被调用次数              一次                  多次

Ajax 错误处理​

// 1.网络畅通，服务器端能接收到请求，服务器端返回的结果不是预期结果
可以判断服务器端返回的状态码，分别进行处理。xhr.status 获取http状态码
// 2.网络畅通，服务器端没有接收到请求，返回404状态码
检查请求地址是否错误
// 3.网络畅通，服务器端能接收到请求，服务器端返回500状态码。
服务器端错误，找后端程序员进行沟通
// 4.网络中断，请求无法发送到服务器端
会触发xhr对象下面的onerror事件，在onerror事件处理函数中对错误进行处理

低版本 IE 浏览器的缓存问题​

[问题]:低版本的IE浏览器，在请求地址不发生变化下Ajax请求只有第一次会真正发送到服务器，后续的请求会从浏览器的缓存中获取结果，即使服务器端数据更新，客户端拿到的仍然是缓存中的旧数据
[解决方案]:在请求地址的后面加请求参数，保证每一次请求中的请求参数的值不相同
// 例如如下代码
xhr.open('get', 'http://www.example.com?t=' + Math.random());

封装 Ajax 函数​

//  定义一个$对象，在里面封装ajax函数，多人开发不易起冲突
let $ = {
  // param封装 将前端对象转换成：key=value&key=value格式
  param: function (dataObj) {
    let datastr = "";
    for (let k in dataObj) {
      datastr += `${k}=${dataObj[k]}&`;
    }
    datastr = datastr.slice(0, -1); // 去掉末尾'&'
    return datastr;
  },

  // ajax封装
  ajax: function (options) {
    // 定义四个参数属性 请求 方式|地址|数据|成功后的回调
    let type = options.type || "GET"; // 默认定为get
    let url = options.url || "";
    let data = options.data || "";
    let success = options.success;

    // 发起ajax请求
    // 1.实例化xhr对象
    let xhr = new XMLHttpRequest();
    // 2.设置请求行
    if (type.toUpperCase() == "GET") {
      url = url + "?" + data;
      data = null; // GET无请求数据
    }
    xhr.open(type, url);
    // POST请求头
    if (type.toUpperCase() == "POST") {
      xhr.setRequestHeader("Content-Type", "application/x-www-form-urlencoded");
    }
    // 3.发送请求数据
    xhr.send(data);
    // 4.监听并处理响应
    xhr.onreadystatechange = function () {
      if (xhr.readyState == 4 && xhr.status == 200) {
        success(xhr.responseText);
      }
    };
  },
};
// 调用封装后的Ajax函数
$.ajax({
    type: 'get',
    url: 'http://www.example.com',
    data: $.param({
        name: 'zs'
        age: 20
        sex: '男'
    }),
    success: function(data){
	 	console.log(data);
    }
})

// 【Promise+原生js请求 封装】
function promiseQueryData(url) {
  return new Promise((resolve, reject) => {
    // 1.实例化XMLHTTPRequest对象
    let xhr = new XMLHttpRequest();
    // 2.设置请求方式 和请求地址
    xhr.open("GET", url);
    // 3.设置请求头 (get可不设置，post必须设置)
    xhr.setRequestHeader("Content-Type", "application/x-www-form-urlencoded");
    // 4.发送请求地址
    xhr.send(null);
    // 5.监听并处理响应
    // 当Ajax状态码发生变化时
    xhr.onreadystatechange = function () {
      if (xhr.readyState != 4) return;
      if (xhr.readyState == 4 && xhr.status == 200) {
        resolve(xhr.responseText);
      } else {
        reject("服务端错误");
      }
    };
  });
}

Fetch​

fetch是一种HTTP数据请求的方式，是XMLHttpRequest的一种替代方案。fetch不是ajax的进一步封装，而是原生js。Fetch函数就是原生js，没有使用XMLHttpRequest对象。

fetch 与 jQuery.ajax()不同点​

// fetch & jQuery.ajax() 主要三种方式的不同
1. 当接收到一个代表错误的 HTTP 状态码时，从 fetch() 返回的 Promise 不会被标    记为 reject， 即使响应的 HTTP 状态码是 404 或 500。相反，它会将 Promise    状态标记为 resolve （但是会将 resolve 的返回值的 ok 属性设置为 false      ），仅当网络故障时或请求被阻止时，才会标记为 reject。

2. fetch() 可以接受跨域 cookies；你也可以使用 fetch() 建立起跨域会话。

3. fetch 不会发送 cookies。除非你使用了credentials 的初始化选项。（自 2017    年 8 月 25 日以后，默认的 credentials 政策变更为 same-origin。Firefox    也在 61.0b13 版本中进行了修改）

axios 基本使用​

// 【1. get请求】
axios.get("http://localhost:3000/adata").then((res) => {
  console.log(res); //{data: "Hello axios!", status: 200, statusText: "OK", headers: {…}, config: {…}, …}
  console.log(res.data);
});
// [1.1 传统url 以 ? 形式传递参数]
axios.get("http://localhost:3000/axios?id=getUrl").then((res) => {
  console.log(res.data); //req.query.id
});
// [1.2 restful 形式传递参数]
axios.get("http://localhost:3000/axios/getRestful").then((res) => {
  console.log(res.data); //req.params.id
});
// [1.3 通过 params 形式传递参数]
axios
  .get("http://localhost:3000/axios", {
    params: {
      id: "getParams",
    },
  })
  .then(function (res) {
    console.log(res.data); //req.query.id
  });

// 【2. delete请求】传参形式和get请求一样
axios.delete("http://localhost:3000/axios?id=deleUrl").then((res) => {
  console.log(res.data);
});
axios
  .delete("http://localhost:3000/axios", {
    params: {
      id: "deleParams",
    },
  })
  .then((res) => {
    console.log(res.data);
  });

// 【3. post请求】
// [3.1 通过选项卡传参]
axios
  .post("http://localhost:3000/axios", {
    uname: "POST_张三",
    pwd: 123456,
  })
  .then((res) => {
    console.log(res);
    console.log(res.data);
  });

// [获取链接中的参数]
console.log(location.search); //拿到 ?后面的参数
let urlData = new URLSearchParams(location.search);
console.log(urlData.get("id"));
console.log(urlData.get("uname"));

// [3.2 通过 URLSearchParams 传参]
// Content-Type: application/json;charset=UTF-8 (Request Payload)
let params = {
  uname: "POST_李四1",
  pwd: 987654,
};
axios.post("http://localhost:3000/axios", params).then((res) => {
  console.log(res.data); //{uname: "POST_李四1", pwd: 987654}
});

// Content-Type: application/x-www-form-urlencoded;charset=UTF-8 (Form Data)
let params2 = new URLSearchParams();
params2.append("uname", "POST_李四2_URLSearchParams");
params2.append("pwd", 987654);
axios.post("http://localhost:3000/axios", params2).then((res) => {
  console.log(res.data);
});

// 【4. put请求】传参形式和post请求一样
axios
  .put("http://localhost:3000/axios/putRestful+body", {
    uname: "PUT_王五",
    pwd: 654321,
  })
  .then((res) => {
    console.log(res.data);
  });

// axios.defaults.timeout = 1; //请求秒失效
axios.defaults.timeout = 1000;

axios.defaults.headers["mytoken"] = "gsg";

// 配置公共的 post 的 Content-Type
axios.defaults.headers.post["Content-Type"] = "application/x-www-form-urlencoded";

// 发起请求
axios.get("axios-json").then((res) => {
  console.log(res.data);
});

axios 拦截器​

axios提供了请求拦截器和响应拦截器

// 请求拦截器
axios.interceptors.request.use(
  (config) => {
    console.log(config.url);
    config.headers.mytoken = "gsg";
    return config;
  },
  function (err) {
    console.log(err); //错误信息
    // return err;
    location.href = "www.baidu.com";
  }
);

// 响应拦截器
axios.interceptors.response.use(
  function (res) {
    console.log(`响应拦截输入：`);
    console.log(res);
    return res.data;
  },
  function (err) {
    console.log(err);
    alert("404，服务器飞了~");
    location.href = "http://www.baidu.com";
  }
);

axios.get("http://localhost:3000/adata").then(function (result) {
  console.log("响应打印结果：");
  console.log(result);
});
