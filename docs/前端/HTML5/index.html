<!DOCTYPE html>
<!-- html是根标签 root标签 根元素 html标签 -->
<!-- lang 代表语言 现在的语言是英语  -->
<!-- lang="zh-cn"  lang="fr" -->
<!-- lang="en"代表是的html中的属性  语法: 属性名="属性值" -->

  <!-- head标签中的内容是给浏览器用的 -->
  <head>
    <!-- meta也是一个标签  -->

    <meta name="viewport" content="width=device-width, initial-scale=1.0" />

    <!-- 让有edge浏览器的电脑 按照edge的内核的方式渲染网页 没有edge的电脑  那就相当于白写 -->

    <!-- 告诉浏览器(更准确的说是给搜索引擎(获取网页信息的软件)))这个网页的标题是什么 让别人容易在百度 google中能轻易的搜到  -->
    <!-- 同时也是网页的标题 显示在tab页中 -->
    <title>我是网页标题</title>
  </head>
  <body>
    <!-- body中的内容是我们写代码的主要区域 -->
  </body>
</html>

HTML5​

HTML 标签​

HTML是超文本标记语言，是软件开发中非常简单的一门技术之一，它是用来编写网页结构和内容的

html 标签由四部分组成： 开始标签

结束标签 内容 content 属性 lang='en'

html 标签分类​
  • 单标签: 只有开始标签没有结束标签 <meta/> <input/> <img/> 在 HTML5 中 单标签的斜杠省略
  • 双标签 有开始标签 有结束标签 div 、html、body、head 、、、
html 标签的关系​

  • 嵌套关系

    也叫父子关系如果一个标签包含另外一个标签那就是父子 || 嵌套 || 包含关系

  • 并列关系

    也叫兄弟关系如果一个标签 不包含另外一个标签那就是 并列 || 兄弟关系

html 标签的属性​
  • 语法: <标签 属性名="属性值"></标签>
  • 属性分为 html 规定的属性(固有属性)和自己规定的属性(自定义属性)
  • 属性名和属性值都必须小写 且用双引号包起来、
html 中常用的标签​
在html中绝不允许 不用标签 直接写内容！！！

语义化标签: 就是你看到这个标签 就明白它里面的内容属于哪一类

  • div 标签 --- 主要用来布局的

  • span 标签 --- 你实在找不到标签可用的时候 用 span 写小东西的时候 比如图标 比如很少的文字

  • 标题标签 - h1 最大的标题 一个页面中只允许存在一个h1 - h2 - h3 - h4 - h5 - h6

  • 段落标签 paragraph

    • p

  • 换行标签

    • br 是一个单标签 只能在 html 中使用 相当于 \n

  • 水平分割线

    • hr 单标签

  • 图片标签

    • img 标签
    • 属性： src：源文件地址 alt：出错时显示的文字 title：鼠标移到图上显示的文字 width：设置宽度 height：设置高度

  • 超链接标签

    • a href 要跳转到哪里 可以是相对地址 也可以是网络地址
    • 属性： color：链接字体颜色 title：链接提示(鼠标移到显示文字) target：打开方式(可转新窗口打开) text-decoration: none：取消下划线
html 中特殊的标签​
pre: 可定义预格式化的文本 保留空格和换行符.
coke: 一个短语标签，用来定义计算机代码文本。
dfn: 斜体效果标签 (同i、em)
kbd: 附带按钮格式的标签

表单标签​

表单: 所谓的表单，其实是网页中为了收集用户信息的一种网页控件或标签。 组成由以下三部分: 表单域、表单控件、提示信息

表单域(Form 标签)​

action：就是url地址 代表了你将要把数据送往哪个地方来处理（表单将要发送数据到哪个应用程序来处理）

method：代表了表单使用哪种提交方法到服务器(GET POST)（不定义表单域数据无法传送到后台服务器）

<form action="" method="“”">
  <!-- 表单线框 -->
  <fieldset>
    <!-- 线框标题 -->
    <legend>form表单标题</legend>
  </fieldset>
</form>

<!-- 表单提交中Get和Post方式的区别

1、get是从服务器上获取数据，post是向服务器传送数据

2、get是把参数数据队列加到提交表单的action属性所指的url中，值和表单内各个字段一一对应，在url中可以看到。post是通过HTTP的post机制，将表单内各个字段与其内容放置在HTML header中一起传送到action属性所指的url地址，用户是看不到这个过程的。

3、对于get方式，服务器端用Request.QueryString获取变量的值，对于post方式，服务器端用Request.Form获取提交的数据

4、get传送的数据量较小，不能大于2KB，post传送的数据量较大，一般被默认为不受限制。但理论上，IIS4中最大量为80KB，IIS5中为100KB

5、get安全性非常低，post安全性较高

-->
表单控件(type 类型)​

包含具体的表单功能项，如文本输入框、密码输入框、提交按钮、重置按钮、、

语法：<input type="表单输入类型">

表单输入类型

<!-- 密码输入框 -->
<input type="password" />

<!-- 文件上传 -->
<input type="file" />

<!-- 时间选取week time date datetime-local -->
<input type="week" />

<!-- 颜色选取 -->
<input type="color" />

<!-- 数字输入 -->
<input type="number" />

<!-- 单选框radio name value checked -->
<input type="radio" />

<!-- 复选框 -->
<input type="checkbox" />

<!-- 提交按钮 -->
<input type="submit" />

<!-- 重置按钮 -->
<input type="reset" />

<!-- 隐藏域：用户看不见的表单，但传输数据会传入后台 -->
<input type="hidden" />

提示信息​

表单中通常还需要包含一些说明性的文字，提示用户进行填写和操作。value、placeholder

表单属性​

  • maxlength 设置控件中最多能输入多少个字符 maximum最大值 length长度

  • readonly 设置控件为只读模式 不能输入 read(阅读)

  • disabled 设置控件为未激活（不能输入）

  • name 设置控件名称

  • id

    设置控件唯一标识 identify

  • value 设置控件默认值

  • placeholder 占位符 设置控件的提示信息

video 标签的属性​

'属性'            '作用'

 height           视频播放器的高度
 controls         显示控件，比如播放按钮
 muted            设置或返回的音频、视频是否应该被静音

 loop             循环播放

 poster           规定视频预播放时显示的图像，直到用户点击播放按钮
