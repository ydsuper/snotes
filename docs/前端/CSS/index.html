CSS

CSS是层叠样式表，也叫CSS样式，也是软件开发中非常简单的一门技术之一，它的主要作用是装饰网页结构和内容的

引入样式​

  • 行内样式​

    特点：写的样式只针对某个指定标签 代码比较繁琐 没有通用性

  <标签 style="css属性名: 属性值;css属性名: 属性值;..."></标签>
  • 内嵌样式(学习中)​

    特点：写的样式只针对某个页面如果项目较复杂 那么会产生冗余代码

<!-- 在head标签中 写style标签 -->
标签名 { css属性名: 属性值; css属性名: 属性值; css属性名: 属性值; }
  • 外链样式(项目中)​

    特点：针对整个项目 对个页面 让代码更加的规范 很少产生冗余代码 通用性是最强的

<!-- 1.先在css文件夹内创建一个css文件，写入样式-->
<!-- 2.再通过link标签，引入创建好的css文件-->
<link rel="stylesheet" type="text/css" href="路径/css文件名" />

标签选择器​
<!-- 标签选择器
    含义: 是指用HTML标签名称作为选择器，按标签名称分类，为页面中某一类标签指定统一的CSS样式。

盒子模型​

组成：​

内容(content)、内边距(padding)、边框(border）、外边距(margin)

  • 内容(content)：

    width宽度、height高度（单位像素(px)）

  • 内边距(padding)： padding-top(上)、padding-bottom(下) padding-left(左)、padding-right(右)

    <!-- 内边距
        padding-top(上): 10px
        padding-right(右): 10px
        padding-bottom(下): 10px
        padding-left(左): 10px
        *简化* ：
        1.上下左右：padding: 10px
        2.上下，左右：padding: 10px 10px
        3.上，左右，下：padding: 10px 10px 10px
        4.上，右，下，左：padding: 10px 10px 10px 10px

    -->

  • 边框(border)： 三部分组成：粗细(none无)、线的样式(solid实线、dashed虚线、dotted点画线)、颜色

    <!-- 边框
        例子：5px代表粗细 solid代表线的样式 red代表颜色
        *简写*：（必须按顺序写）
        border:5px solid red
        border:5px dashed red
        border:5px dotted red
        *扩写*：
        border-width:5px
        border-style:solid
        border-color:red

    -->

  • 外边距(margin)： margin-top(上)、margin-bottom(下) margin-left(左)、margin-right(右)

    <!-- 外边距
        margin-top(上): 10px
        margin-right(右): 10px
        margin-bottom(下): 10px
        margin-left(左): 10px
        *简化*：
        1.上下左右：margin: 10px
        2.上下，左右：margin: 10px 10px
        3.上，左右，下：margin: 10px 10px 10px
        4.上，右，下，左：margin: 10px 10px 10px 10px

        **外边距的使用**：
        让一个块级盒子实现水平居中必须：
        1.盒子必须指定了宽度(width)；
        2.然后给左右外边距设置成auto；
        margin:0 auto(水平居中)

    -->
外边距合并​

如果有两个盒子"竖直"相邻的时候，这两个盒子之间产生的距离等于最大的那个外边距 解决：为了避免外边距合并，最好只给其中一个写，不要都写

外边距塌陷​
<!-- 外边距塌陷
    现象：有两个div，分别是a和b，b这个元素是a元素的子元素，当给b加margin- top的时候，按道理，应该是a不动，然后b向下移动一段距离，但发现a和b一起被margin-top扯了下来（只有margin-top才会有塌陷）

    **解决方案**：
    1.给父元素添加 border
    2.给父元素添加 overflow:hidden;（溢出:隐藏）

盒子尺寸​
<!--
	▓ 盒子尺寸：
	  box-sizing: content-box | border-box | inherit 
	▓ 属性值：
	  ● content-box：这是由CSS2.1规定的宽度高度行为，宽度和高度分别应用到元素的内容框，在宽度和高度之外绘制元素的内边距和边框；（默认加框加内边距会扩大整体宽高）

	  ● border-box：为元素设定的宽度和高度决定了元素的边框盒，就是说，为元素指定的任何内边距和边框都将在已设定的宽度和高度内进行绘制。通过从已设定的宽度和高度分别减去边框和内边距才能得到内容的宽度和高度;（加框加内边距会往内部内容挤压，不会影响整体宽高）

	  ● inherit：规定应从父元素继承box-sizing属性的值;
	▓ 盒子尺寸应用场景：
	  * {box-sizing: border-box}


-->

复合选择器​

复合选择器是建立在基础选择器之上,对基本选择器进行组合形成的。 在CSS中，我们可以把选择器的类型分为'基础选择器'和'复合选择器'

后代选择器​

后代选择器:又称为包含选择器，可以选择父元素里面的子元素。其写法就是把外层标签 写在前面，内层标签写在后面，中间用空格分隔。当标签发生嵌套时，内层标签就成为外 层标签的后代。

<!-- 后代选择器：

	▓ 标志：'空格'
    ▓ 语法：
	  元素1 元素2 {样式声明};
	▓ 例如：
	  div span {样式声明} 【选择div里面的span标签】;
	▓ 注意说明：
	  ● 元素1和元素2中间用空格隔开;
	  ● 元素1是父级,元素2是子级，最终选择的是元素2;
	  ● 元素2可以是儿子或孙子，主要是元素1的后代即可，元素1和元素2可以是任意         选择器(类选择器、标签选择器、、);

-->

三大特性​

层叠性​

相同选择器设置了相同的样式，此时一个样式就会覆盖(层叠)另一个冲突的样式，层叠性主要解决样式冲突的问题。层叠性就是:长江后浪推前浪，前浪死了。

对于相同选择器中的相同属性，那个选择器里标签近，就使用哪个属性，称为就近原则，层叠也叫覆盖

<!-- 层叠性：

	▓ 就近原则：
	  样式冲突，遵循的原则是就近原则，哪个样式离结构近，就执行哪个样式，样式不冲突，不会层叠。
	▓ 示例：
	  div{
	  color: red;
	  }
	  div{
	  color: blue;
	  }
	 【结果是蓝色】
	
-->
继承性​

现实中，我们继承了父亲的姓，在css中，子元素继承了父元素的某些样式，如文本颜色和字号。简单理解就是:子承父业。继承性好比龙生龙，凤生凤

<!-- 继承性：
	▓ 说明：
	  ● 恰当地使用继承可以简化代码，降低了CSS样式的复杂性
	  ● 子元素可以继承父元素的样式(text- ,font-,line-这些元素开头的可以继承，color也可以)（a标签、span标签是特殊的，不能继承）

-->
优先级性​

当多个选择器把样式应用到同一个元素上，优先应用哪个样式，就是优先级。

<!-- 优先级性：
	▓ 说明：
	  ● 选择器相同，则执行层叠性
	  ● 选择器不同，则根据选择器权重执行
		○ 选择器：继承(子承父) 或 *(通配符)
          选择器权重：0, 0, 0, 0
		○ 选择器：标签选择器
          选择器权重：0, 0, 0, 1
		○ 选择器：类选择器 伪类选择器
          选择器权重：0, 0, 1, 0
		○ 选择器：ID选择器
          选择器权重：0, 1, 0, 0
		○ 选择器：行内样式 style=""
          选择器权重：1, 0, 0, 0
		○ 属性值后面加：!important（代表至高无上的权重）
                 权重：无穷大+∞

-->

<style>
  /*❶ 0001 + 0001 + 0001 = 0003 */

  }

  }

  ul li {
  }
  /*❹ 0001 */
  li {
  }

<!--【所以：最后选择权重最高的那个❷】-->
<!-- ▶优先级注意点◀：

	● 权重是由4组数字组成的，但是不会有进位
	● 可以理解为类选择器永远大于元素选择器，ID选择器永远大于类选择器，以此类推

元素浮动​

网页布局的本质一用CSS来摆放盒子，把盒子摆放到相应位置。CSS提供了三种传统布局方式(简单说，就是盒子如何进行排列顺序): '标准流'、'浮动'、'定位'三种布局方式都是用来摆放盒子的，盒子摆放到合适位置,布 局自然就完成了

网页布局第一准则:

● 多个块级元素竖着排列找 标准流;
● 多个块级元素横着排列找 浮动;
● 多个块级元素叠着排列找 定位。
普通流(标准流)​

所谓的标准流就是标签按照规定好默认的方式排列。 下面都是标准流布局，我们前面学习的都是标准流布局。标准流是最基本的布局方式。

<!-- 标准流:
	▓ 特性：
	● 块级元素会独占一行，从上向下顺序排列
	● 行内元素会按照顺序，从左到右顺序排列，碰到父元素边缘则会自动换行
	▓ 说明:
	  实际开发中，一个页面基本都包含了这三种布局方式(移动端会学习新的布局方式)

-->
浮动​

浮动是网页布局方式之一，它是让网页元素脱离标准流的方式之一，利用浮动，我们可以改变元素默认的排列方式。 浮动最典型的应用:可以让多个块级元素在一行内排列显示，并且没有空隙。

<!-- 浮动：
	▓ 语法:
	  选择器:{float: 属性值;}
	▓ 参数：
	● 参数值：none
	  含义：元素不浮动
	● 参数值：left
	  含义：元素向左浮动
	● 参数值：right
	  含义：元素向右浮动

-->
<!-- 浮动的重要特性：

	● 脱离标准普通流的控制(浮)移动到指定位置(动),俗称浮动
	● 浮动的盒子不再保留原先的位置
	● 如果多个盒子都设置了浮动，则他们会按照属性值一行内显示并且顶端对齐排列
	● 浮动的元素是互相贴合的，没有缝隙，如果父元素装不下这些浮动的元素，会换行
	● 任何元素都可以浮动。不管原先是什么模式的元素，添加浮动之后具有与行内块元素相似的特性
	● 如果块级盒子没设置宽度,默认宽度和父级一样,但添加浮动后，宽度由内容决定
	● 浮动的盒子中间是没有缝隙的，是紧挨着一起的
	● 行内元素同理

-->
<!-- 浮动元素使用经验：

	浮动元素经常和标准流父级搭配使用。为了约束浮动元素位置，我们网页布局一般采取的策略是：先用标准流的父元素排列上下位置，然后内部子元素如果在一行采取浮动排列左右位置，符合网页布局第一准则。

-->

清除浮动​

本质： 清除浮动的本质是清除浮动元素造成的影响，准确的说是对页面布局造成的影响 如果父盒子本身有高度，则不需要清除浮动 清除浮动之后，父级就会根据浮动的子盒子自动检测高度。

<!-- 清除浮动：清除兄弟元素的浮动
	▓ 语法:
	  选择器{ clear:属性值}
	▓ 属性：
	  ● 参数值：left
	    含义：不允许左侧有浮动元素(清除左侧浮动的影响)
	  ● 参数值：right
	    含义：不允许右侧有浮动元素(清除右侧浮动的影响)
	  ● 参数值：both

主侧轴方向​

定义主轴的方向，侧轴会随之而变，侧轴只有right和bottom两个方向

<!-- 主轴方向：
	▓ 语法：
	  flex-direction: row(行) | row-reverse(倒行) | column(列) | column-reverse(倒列)
	▓ 属性值
	  ● row：方向自左而右（默认）【→】
	  ● row-reverse：方向自右而左 【←】
	  ● column：方向自上而下 【↓】
	  ● column-reverse：方向自下而上 【↑】

	▓ 侧轴方向
	  主轴方向为水平方向：自上而下 【↓】
	  主轴方向为垂直方向：自左而右 【→】


-->
主轴属性​

justify-content定义伸缩项目（子元素）在主轴的对齐方式（给父元素添加）

<!-- 伸缩项目在主轴的对齐方式：
	▓ 语法：
	  justify-content: flex-start | flex-end | center | space-between(两端对齐) | space-around(空间环绕)
	▓ 属性值
	  ● flex-start：主轴方向开始位置对齐
	  ● flex-end：主轴方向结束位置对齐
	  ● center：主轴方向居中位置对齐
	  ● space-around：主轴方向空间环绕对齐（两端位置不占据，平分剩余空间）
	  ● space-between：主轴方向两端位置对齐（先两边贴边，再平分剩余空间）

-->
侧轴属性​
<!-- 侧轴属性：
	▓ 换行
	  flex-wrap: nowrap(默认不换行) | wrap(换行) | wrap-reverse(反换)

	▓ 设置伸缩项目不换行在侧轴的对齐方式
	  align-items: stretch(拉伸) | flex-start | flex-end | center

	▓ 设置伸缩项目换行后在侧轴的对齐方式
	  align-content: stretch(拉伸) | flex-start | flex-end | center | space-between(两端对齐) | space-around(空间环绕)


-->
伸缩项目的属性​
<!-- 伸缩项目的属性:【添加对象都是伸缩项目 即: 子元素】

	▓ flex: ?; (一般值填写1)
	  设置伸缩项目在伸缩容器中所占的剩余空间（除去固定宽高元素）的比例
	  
	▓ order: ?; (-∞, +∞)
	  设置伸缩项目的排序顺序 默认顺序是html标签 值越小在前 (-∞, +∞)
	 
	▓ align-self: ?; (stretch | flex-start | flex-end | center)
	  设置自我对齐方式，关于某个伸缩项目的对齐方式，和align-items的属性值完全一样（给子元素设置）
	  
	▓ flex-flow: row nowrap;(默认值)【添加给父元素】
	  flex-flow 属性是 flex-direction 和 flex-wrap 属性的复合属性，其用于设置或检索弹性盒模型对象的子元素排列方式。


-->

准备工作​

  • index.html 首页文件 首页文件固定写法
  • css 文件夹 存放css文件 必须是自己写的
  • lib 文件夹 library库 存放第三方的库 无论是css库还是js库
  • upload 文件夹 上传的商品图片等 一定是用户上传的
  • fonts 文件夹 存放新字体的，还有字体图标库里的字体文件的（5种 eot svg ttf woff woff2）
  • img 文件夹 图片存放 很长时间在网页种不变的图片存放
  • video 文件夹 视频存放
  • audio 文件夹 音频存放

favicon 制作和使用​

制作​
  1. 先准备一张方形图 图片大小不能超过 500k
  2. 进入网站 http://www.bitbug.net/
  3. 看网页按步骤进行操作 最后点击生成 ico 图标 会自动下载
使用​
  1. 把后缀 .ico 的图片放到项目的文件夹里
  2. 在首页的 head 标签中使用link引入：link:favicon（快捷）

TDK 搜索引擎优化​

title​
  • 介绍​

    网页的标题 title 具有不可替代性，是我们内页的第一个重要标签，是搜索引擎了解网页的入口和对网页主题归属的最佳判断点。

  • 格式​

    网站名(产品名) - 网站的介绍（尽量不要超过 30 个汉字）

description​

网站描述 简要说明网站主要是做什么的

keywords​

keywords 是页面关键字，是搜索引擎关注点之一。keywords 最好限制为 6~8 个关键词，关键词之间用英文逗号隔开
