导入 scss 文件​

sass 中的@import 和 css 中的@import​
  • sass 是开发时使用 先编译 后上线使用 压根儿就不存在多个 css 引用的问题 只是在编译过程中需要点时间 但是上线之后丝毫不影响用户体验 所以推荐用 @import 在 sass 中没有兼容性
  • css 是上线之后网页加载需要样式的时候下载 如果在 css 中使用@import 会让 css 下载两次以上 会让网页渲染变慢 所以是无用功 不用 @import 有兼容性

二倍图​

对于相同尺寸的屏幕 因为分辨率不同（iPhone 3Gs 320*480 iPhone 640*960）导致同样的图片在不同的手机中显示不一样 在高分辨率手机中 图片会模糊或缩小 因此需要解决：通过使用二倍图，移动端布局都是由设计师设计的二倍图 640 750 1125

媒体查询​

媒体查询的作用​

根据终端（媒介|媒体）的特性（网页宽高、设备宽高、横竖屏、、），可以给不同的样式

媒体查询的用法​

关键字：only(仅仅) not(非) and(且) or(用逗号表示)

不同的设备应用不同的css文件

语法：
<link
  rel="stylesheet"
  type="text/css"
  href="css的路径"
  media="过滤条件（screen and (width: xxx)）"
/>

不同的设备应用不同的css样式

语法：@media screen and (width: xxx) and (height: xxx) { css}

媒体特性​

1. width | min-width | max-width//定义输出设备中的页面可见区域宽度。

2. height | min-height | max-height//定义输出设备中的页面可见区域高度。

3. device-width | min-device-width | max-device-width//定义输出设备的屏幕可见宽度。（不可变）

4. device-height | min-device-height | max-device-height//定义输出设备的屏幕可见高度。（不可变）

注：设备宽度(device-width)指的是显示该页面的屏幕宽度，这里指的是屏幕宽度，通常可以使用于移动设备的，因为这样的设备具有更小的显示区域。宽度(width)指的是浏览器窗口的宽度，特定媒体类型的渲染视区，对于桌面的操作系统来说，其实就是当前浏览器的宽度（并且是包括滚动条的）。且宽度默认等于屏幕宽度（width=device-width）

5. orientation: portrait(竖屏) | landscape(横屏)//定义设备横/竖屏

扩展：
1. aspect-ratio | min-aspect-ratio | max-aspect-ratio//定义输出设备中的页面可见区域宽度与高度的比率

2. device-aspect-ratio | min-device-aspect-ratio | max-device-aspect-ratio//定义输出设备的屏幕可见宽度与高度的比率。

3. color | min-color | max-color//定义输出设备每一组彩色原件的个数。如果不是彩色设备，则值等于0

4. color-index | min-color-index | max-color-index//定义在输出设备的彩色查询表中的条目数。如果没有使用彩色查询表，则值等于0

5. monochrome | min-monochrome | max-monochrome  //定义在一个单色框架缓冲区中每像素包含的单色原件个数。如果不是单色设备，则值等于0

6. resolution | min-resolution | max-resolution //定义设备的分辨率。如：96dpi, 300dpi, 118dpcm

7. scan | grid  //定义电视类设备的扫描工序|用来查询输出设备是否使用栅格或点阵。

rem 布局​

rem​

rem 是一个相对长度单位

px 相对于显示器屏幕分辨率
em 相对于自己的font-size
rem 相对的是html的font-size

rem 原理​

  1. 假设设计图为 640（还有 750,1125 的），人为的分成 20份，计算一份有多少像素（640 / 20 = 32px/份）
  2. 量出设计图中元素像素大小，再计算该元素占设计图的多少份 (该大小(单位: rem) / 32px/份 = x份数（单位：rem）)
  3. 适配手机 设手机宽度为width，计算 html 的 font-size 值，设为y
  4. 【关键】解析第二步，转换 rem值，得出该元素占设计图的多少像素 （因为 1份 = 1rem = y，所以得出该元素所占像素结果就是：x份数 * y像素 = 该元素所占像素）

响应式布局​

响应式开发原理​

使用媒体查询针对不同宽度的设备进行布局和样式的设置，从而适配不同设备的目的。

1.超小屏幕（手机）：小于768px
2.小屏幕（平板）：大于等于768px 小于992px
3.中等屏幕（桌面显示器）：大于等于992px 小于1200px
4.宽屏设备（大桌面显示器）：大于等于1200px

​

响应式布局容器​

响应式开发首先需要一个布局容器 ".container"，使用媒体查询，根据布局容器的宽度进行样式调整

1.超小屏幕（手机）：小于768px ----设置宽度为100%

2.小屏幕（平板）：大于等于768px 小于992px ----设置宽度为750px

3.中等屏幕（桌面显示器）：大于等于992px 小于1200px ----设置宽度为970px

4.宽屏设备（大桌面显示器）：大于等于1200px ----设置宽度为1170px

bootstrap 的介绍​

Bootstrap来自Twitter（推特），是目前(以前)最受欢迎的前端框架（前端框架的祖宗），Bootstrap 是基于HTML、CSS和JAVASCRIPT的，它简洁灵活,使得Web开发更加快捷。

● 中文官网: http://www.bootcss.com/

● 官网: http://getbootstrap.com/

● 推荐使用: http://bootstrap.css88.com/

`框架`：顾名思义就是一套架构, 它有一套齜较完整的网页功能解决方案, 而且控制权在框架本身, 有预制样式库、组件和插件。使用者要按照框架所规定的某种规范进行开发。

bootstrap 的优点​

  • 标准化的 html+css 编码规范
  • 提供了一套简洁、直观、强悍的组件
  • 有自己的生态圈，不断的更新迭代
  • 让开发更简单，提高了开发的效率

bootstrap 版本​

  • 2.x.x：停止维护,兼容性好,代码不够简洁,功能不够完善。
  • 3.x.x：目前使用最多,稳定,但是放弃了 IE6-IE7。对 IE8 支持但是界面效果不好,偏向用于开发响应式布局、移动设备优先的 WEB 项目。
  • 4.x.x： 最新版,目前还不是很流行

bootstrap 栅格系统 重点​

栅格系统简介​

栅格系统英文为"gridsystems" ,也有人翻译为“网格系统”，它是指将页面布局划分为等宽的列 ,然后通过列数的定义来模块化页面布局。 Bootstrap提供了一套响应式、 移动设备优先的流式栅格系统，随着屏幕或视口( viewport)尺寸的增加，系统会自动分为最多12列。

栅格参数​

栅格选项参数​

栅格系统用于通过一系列的行(row)与列(column)的组合来创建页面布局，使用单一的一组 .col-md-* 栅格类，就可以创建一个基本的栅格系统

<!-- 栅格选项参数
	▓ 超小屏幕（手机）<768px
	● 类前缀：.col-xs-
	▓ 小屏设备（平板）>=768px
	● 类前缀：.col-sm-
	▓ 中等屏幕（桌面显示器）>=992px
	● 类前缀：.col-md-
	▓ 宽屏设备（大桌面显示器）>=1200px
	● 类前缀：.col-lg-

    ▓ 注意：
	  ● 行( row )必须放到.container布局容器里面
	  ● 我们实现列的平均划分需要给列添加类前缀
	  ● xs-extra small：超小；sm-small：小；md-medium：中等；lg-large ：大;
	  ● 列(column)大于12,多余的“列(column)"所在的元素将被作为一个整体另起一行排列
	  ● 每一列默认有左右15像素的padding
	  ● 可以同时为一列指定多个设备的类名，以便划分不同份数 例如class="col-xs-2 col-sm-4 col-md-6 col-lg-12"


-->
列嵌套​

栅格系统内置的栅格系统将内容再次嵌套。简单理解就是一个列内再分成若干份小列。我们可以通过添加一个新的.row元素和一系列.col-sm-*元素到已经存在的.col-sm-*元素内。

<!-- 列嵌套 -->
 <div class="container">
    <div class="row">
      <div class="col-md-6">
        <!-- 我们列嵌套最好加1个行 row 这样可以取消父元素的padding值 而且高度自动和父级一样高 -->
        <div class="row">
          <div class="col-md-4"></div>
          <div class="col-md-6"></div>
        </div>
      </div>
      <div class="col-md-6"></div>
    </div>
  </div>
  </div>
列偏移​

使用.col-md-offset-*类可以将列向右侧偏移。这些类实际是通过使用*选择器为当前元索增加了左侧的边距(margin)。

<!-- 列偏移 -->
<div class="container">
  <div class="row">
    <div class="col-md-4">左</div>
    <!-- 偏移4个格 -->
    <div class="col-md-4 col-md-offset-4">右</div>
  </div>
</div>
列排序​

通过使用.col-md-push-*和.col-md-pull-*类就可以很容易的改变列(column)的顺序。

<!-- 列排序 -->
<div class="container">
  <div class="row">
    <!-- push左 pull右 -->
    <div class="col-md-4 col-md-push-8">左</div>
    <div class="col-md-8 col-md-pull-4">右</div>
  </div>
